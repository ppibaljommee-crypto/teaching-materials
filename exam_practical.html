วิทยาการคำนวณ (Python)

"โปรแกรมคำนวณบิลร้านค้า" — ใช้ตัวแปรครบทุกชนิด (ไม่มี if-else)

เขียนโปรแกรม Python รับข้อมูลการซื้อของ คำนวณราคารวม และตรวจว่าเงินพอจ่ายไหม (แสดงผลเป็น True/False)
🔤 ต้องใช้ตัวแปรครบทั้ง 4 ชนิด
ชนิดตัวแปรตัวอย่างในโจทย์
str (ข้อความ)ชื่อลูกค้า, ชื่อสินค้า
int (จำนวนเต็ม)จำนวนชิ้นที่ซื้อ
float (ทศนิยม)ราคาต่อชิ้น, เงินที่มี
bool (จริง/เท็จ)เงินพอจ่ายหรือไม่ (True/False)
📋 ให้เด็กเขียนโปรแกรมทำสิ่งนี้
  1. รับ ชื่อลูกค้า (str) และ ชื่อสินค้า (str) ด้วย input()
  2. รับ จำนวนชิ้น (int) และ ราคาต่อชิ้น (float)
  3. รับ เงินที่ลูกค้ามี (float)
  4. คำนวณ ราคารวม = จำนวนชิ้น × ราคาต่อชิ้น และ เงินทอน = เงินที่มี − ราคารวม
  5. สร้างตัวแปร bool: เงินพอ = เงินที่มี >= ราคารวม แล้ว print ออกมาตรงๆ (True/False)
  6. เซฟไฟล์ตั้งชื่อ "บิลร้านค้า_ชื่อตัวเอง.py"
✅ ตัวอย่างโค้ดเฉลย (สำหรับครูตรวจ)
# รับข้อมูล
ชื่อลูกค้า = input("ชื่อลูกค้า: ")          # str
สินค้า = input("ชื่อสินค้า: ")             # str
จำนวน = int(input("จำนวนชิ้น: "))          # int
ราคาต่อชิ้น = float(input("ราคาต่อชิ้น: ")) # float
เงินที่มี = float(input("เงินที่มี: "))     # float

# คำนวณ
ราคารวม = จำนวน * ราคาต่อชิ้น
เงินทอน = เงินที่มี - ราคารวม
เงินพอ = เงินที่มี >= ราคารวม               # bool (True/False)

# แสดงผล
print("ลูกค้า:", ชื่อลูกค้า)
print("สินค้า:", สินค้า)
print("ราคารวม:", ราคารวม, "บาท")
print("เงินทอน:", เงินทอน, "บาท")
print("เงินพอจ่ายไหม:", เงินพอ)   # แสดง True หรือ False
🎯 เกณฑ์ให้คะแนน (10 คะแนน)
รายการคะแนน
ใช้ตัวแปร str ถูกต้อง (ชื่อลูกค้า/สินค้า)1
ใช้ตัวแปร int ถูกต้อง + แปลงด้วย int()2
ใช้ตัวแปร float ถูกต้อง + แปลงด้วย float()2
สร้างตัวแปร bool จากการเปรียบเทียบ + print True/False2
คำนวณราคารวม + เงินทอน ถูกต้อง2
โปรแกรมรันได้ไม่ error + เซฟไฟล์ .py1
💡 ครบ 4 ชนิดตัวแปร + input/print + การคำนวณ — โดยไม่ต้องใช้ if-else (เงินไม่พอ → เงินทอนติดลบ + เงินพอเป็น False)
