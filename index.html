วิธีที่ 1 — Shared Folder บน LAN (ง่ายที่สุด)

ขอให้ IT โรงเรียนแชร์โฟลเดอร์นี้ในวง LAN → นักเรียนเปิดจาก File Explorer


วิธีที่ 2 — Local Web Server จากเครื่องครู (ไม่ต้องการ IT)

1. เปิด Command Prompt ในโฟลเดอร์นี้
2. พิมพ์: python -m http.server 8080
3. นักเรียนเปิดเบราว์เซอร์ พิมพ์: http://[IP ครู]:8080
4. ดู IP ครูได้จาก CMD: ipconfig → IPv4 Address
