👩‍🏫 เขียน Pseudocode บนกระดานให้นักเรียนดู

💻 Pseudocode คืออะไร?

Pseudocode = ภาษากึ่งโปรแกรม
ใช้อธิบายขั้นตอนก่อนเขียนโค้ดจริง
ไม่มี syntax เคร่งครัด แต่อ่านแล้วเข้าใจทันที

// หาค่าเฉลี่ย 3 วิชา START INPUT score1, score2, score3 SET avg = (score1 + score2 + score3) / 3 IF avg >= 50 THEN OUTPUT "ผ่าน" ELSE OUTPUT "ไม่ผ่าน" ENDIF END
👩‍🏫 ทดสอบ trace โค้ด — ถามว่าถ้า score1=40,score2=60,score3=50 ได้ผลอะไร?

🧠 Trace the Pseudocode

// กำหนดให้: score1=40, score2=60, score3=50 SET avg = (40 + 60 + 50) / 3 // avg = ? IF avg >= 50 THEN OUTPUT "ผ่าน" ELSE OUTPUT "ไม่ผ่าน" ENDIF
avg = 150/3 = 50 → 50 ≥ 50 → OUTPUT "ผ่าน" ✅
👩‍🏫 ทดสอบ: ให้นักเรียนเขียน Pseudocode ง่ายๆ บนกระดาษแล้วแชร์

📊 ด้านซ้าย: Flowchart

  • • ใช้สัญลักษณ์ถูกต้อง
  • • มีลูกศรเชื่อมทุกขั้นตอน
  • • เริ่มต้น/สิ้นสุดชัดเจน
  • • ตั้งชื่อโปรแกรม

💻 ด้านขวา: Pseudocode

  • • START … END ครบ
  • • INPUT / OUTPUT ชัดเจน
  • • IF…THEN…ELSE ถูกต้อง
  • • สอดคล้องกับ Flowchart

🎤 การนำเสนอ (~3 นาที)

• อธิบาย Flowchart ตามลำดับ | • อ่าน Pseudocode ทีละบรรทัด | • ตอบคำถามเพื่อน
