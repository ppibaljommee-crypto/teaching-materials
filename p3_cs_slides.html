🎁 ทำของขวัญให้คุณแม่ — แตกออกได้กี่ส่วน?

ของขวัญ = ดอกไม้กระดาษ + การ์ด + กล่องตกแต่ง

ดอกไม้ → หาแบบ → ตัดกระดาษ → พับ → ติดกาว
การ์ด → เขียนข้อความ → ตกแต่ง
กล่อง → วัดขนาด → พับกล่อง → ตกแต่ง
👩‍🏫 ทดสอบความเข้าใจ ให้เด็กตอบพร้อมกัน
