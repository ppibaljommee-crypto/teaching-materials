👩‍🏫 ให้นักเรียนลองผลัก/ดึงโต๊ะ ถามว่า "เกิดอะไรขึ้น?" นำเข้าสู่ความหมายของแรง

ผลัก หรือ ดึง... คือ "แรง"

แรง (Force) คือ การกระทำที่ผลักหรือดึงวัตถุ
ทำให้วัตถุ เคลื่อนที่ หยุด เปลี่ยนทิศ หรือเปลี่ยนรูปร่าง

👐 แรงในชีวิตประจำวัน

• ดึงประตู เปิด-ปิด

• เตะลูกบอล

• กดดินน้ำมันให้แบน

📐 แรงมี 2 สิ่งสำคัญ

• ขนาด — แรงมากหรือน้อย

• ทิศทาง — ไปทางไหน

👩‍🏫 อธิบายว่าแรงเขียนแทนด้วยลูกศร ความยาวลูกศร = ขนาดแรง หัวลูกศร = ทิศทาง

➡️ แรงเขียนแทนด้วย "ลูกศร"

📏 ความยาวลูกศร

บอกขนาดของแรง
ยาว = แรงมาก

➡️ หัวลูกศร

บอกทิศทางของแรง

🅝 หน่วยของแรง

นิวตัน (N)

วัตถุ 📦 ———▶

ลูกศรชี้ขวา = แรงผลักไปทางขวา

👩‍🏫 ยกตัวอย่างผลของแรง ให้นักเรียนจับคู่เหตุการณ์กับชนิดของผล

✨ ผลของแรงต่อวัตถุ

🏃 เปลี่ยนการเคลื่อนที่

• ทำให้วัตถุที่หยุดอยู่ เริ่มเคลื่อนที่

• ทำให้เร็วขึ้น ช้าลง หรือหยุด

• ทำให้เปลี่ยนทิศทาง

🟡 เปลี่ยนรูปร่าง

• กดดินน้ำมัน → แบน

• ดึงยาง → ยืดยาว

• บีบกระป๋อง → บุบ

👩‍🏫 แสดงเครื่องชั่งสปริง (spring balance) อธิบายว่าวัดแรงเป็นนิวตัน ยิ่งดึงแรง สปริงยืดมาก ตัวเลขมาก

⚖️ การวัดแรง

เครื่องชั่งสปริง (Spring Balance)

• ใช้วัดขนาดของแรง หน่วยเป็น นิวตัน (N)

• ภายในมีสปริง — ดึงแรงมาก สปริงยืดมาก

• อ่านค่าตรงขีดที่เข็ม/ปลายสปริงชี้

• 1 กิโลกรัม มีน้ำหนักประมาณ 10 นิวตัน

👩‍🏫 กิจกรรมที่ 1 (ชม.1): ให้นักเรียนใช้เครื่องชั่งสปริงดึงวัตถุต่างๆ บันทึกค่าแรง เปรียบเทียบ
กิจกรรมที่ 1
⚖️

กิจกรรม: วัดแรงด้วยเครื่องชั่งสปริง

📝 โจทย์

1. ใช้เครื่องชั่งสปริงดึงวัตถุ 3 อย่างให้เริ่มเคลื่อนที่
2. อ่านและบันทึกค่าแรง (นิวตัน) ของแต่ละชิ้น
3. เรียงลำดับวัตถุจากใช้แรงน้อย → มาก
4. ลงความเห็น: วัตถุแบบใดต้องใช้แรงมาก เพราะอะไร?

👩‍🏫 เริ่ม ชม.2 ถามว่า "ถ้ามีหลายคนช่วยกันดันรถ แรงจะรวมกันไหม?" นำเข้าแรงลัพธ์
ชั่วโมงที่ 2 — แรงลัพธ์

➕ แรงลัพธ์ คืออะไร?

แรงลัพธ์ (Resultant Force) คือ ผลรวมของแรงทุกแรง
ที่กระทำต่อวัตถุชิ้นเดียวกัน

เมื่อมีหลายแรงกระทำพร้อมกัน เรารวมเป็น "แรงเดียว" ที่ให้ผลเหมือนกัน

👩‍🏫 แรงทิศเดียวกันให้บวกกัน ยกตัวอย่าง 2 คนช่วยกันดันรถไปทางเดียวกัน

⬅️⬅️ แรงทิศเดียวกัน → บวกกัน

▶ 5 N
▶ 3 N
=
▶ 8 N

แรง 2 แรงไปทางเดียวกัน → แรงลัพธ์ = 5 + 3 = 8 N
ทิศไปทางเดิม วัตถุเคลื่อนที่แรงขึ้น

👩‍🏫 แรงทิศตรงข้ามให้ลบกัน แรงลัพธ์มีทิศไปทางแรงที่มากกว่า ยกตัวอย่างชักเย่อ

◀▶ แรงทิศตรงข้าม → ลบกัน

◀ 7 N
3 N ▶
=
◀ 4 N

แรงตรงข้ามกัน → แรงลัพธ์ = 7 − 3 = 4 N
ทิศไปทางแรงที่มากกว่า (ทางซ้าย)

👩‍🏫 แรงลัพธ์เป็นศูนย์ = สมดุล วัตถุอยู่นิ่งหรือเคลื่อนที่สม่ำเสมอ ยกตัวอย่างชักเย่อเสมอกัน

⚖️ แรงลัพธ์ = 0 → สมดุล

🟰 แรงลัพธ์เป็นศูนย์

• แรงตรงข้ามขนาดเท่ากัน เช่น 5 N ◀ ▶ 5 N

• แรงลัพธ์ = 5 − 5 = 0 N

• วัตถุ อยู่นิ่ง หรือเคลื่อนที่ด้วยความเร็วคงที่

↔️ แรงลัพธ์ไม่เป็นศูนย์

• แรงไม่เท่ากัน เหลือแรงลัพธ์

• วัตถุ เปลี่ยนการเคลื่อนที่

• เคลื่อนไปทางแรงลัพธ์

👩‍🏫 ให้นักเรียนลองคำนวณตามตัวอย่างชักเย่อ ทีมไหนชนะ แรงลัพธ์เท่าไหร่

🧮 ตัวอย่าง: ชักเย่อ

ทีม A ดึงไปทางซ้ายด้วยแรง 120 N
ทีม B ดึงไปทางขวาด้วยแรง 100 N

แรงตรงข้าม → แรงลัพธ์ = 120 − 100 = 20 N ไปทางซ้าย → ทีม A ชนะ ✅

ชั่วโมงที่ 3 — แรงเสียดทาน

🛑 แรงเสียดทาน คืออะไร?

แรงเสียดทาน (Friction) คือ แรงที่ต้านการเคลื่อนที่
เกิดระหว่าง ผิวสัมผัสของวัตถุ 2 ผิว มีทิศ ตรงข้าม กับการเคลื่อนที่

เช่น เลื่อนกล่องบนพื้น จะรู้สึกมีแรงต้านไม่ให้เลื่อนง่าย

👩‍🏫 2 ปัจจัยหลัก: ลักษณะผิวสัมผัส และน้ำหนักวัตถุ ให้ลองทายว่าพื้นแบบใดเสียดทานมากกว่า

🔧 อะไรมีผลต่อแรงเสียดทาน?

🪵 ลักษณะผิวสัมผัส

• ผิว ขรุขระ → แรงเสียดทาน มาก

• ผิว เรียบลื่น → แรงเสียดทาน น้อย

• เช่น พื้นทราย เทียบกับพื้นกระเบื้องมัน

⚖️ น้ำหนักของวัตถุ

• วัตถุ หนัก กดผิวมาก → เสียดทาน มาก

• วัตถุ เบา → เสียดทาน น้อย

• เช่น ลากกล่องหนักยากกว่ากล่องเบา

🎯 Quiz: ลากกล่องบนพื้นแบบใดต้องออกแรงมากที่สุด?

ผิวยิ่งขรุขระ แรงเสียดทานยิ่งมาก จึงต้องออกแรงลากมากที่สุด ✅
👩‍🏫 เริ่ม ชม.4 อภิปรายว่าแรงเสียดทานมีทั้งประโยชน์และโทษ ให้นักเรียนยกตัวอย่างจากชีวิตจริง
ชั่วโมงที่ 4

⚖️ ประโยชน์ และ โทษ ของแรงเสียดทาน

✅ ประโยชน์

• เดินได้โดยไม่ลื่นล้ม

• เบรกรถ จักรยาน ให้หยุด

• จับสิ่งของได้ ไม่หลุดมือ

• จุดไม้ขีดไฟ (ถู)

❌ โทษ

• ทำให้เครื่องจักร/รองเท้าสึกหรอ

• เกิดความร้อน

• ทำให้เคลื่อนที่ช้า เปลืองพลังงาน

👩‍🏫 สอนวิธีเพิ่ม/ลดแรงเสียดทาน ให้นักเรียนจับคู่สถานการณ์ว่าควรเพิ่มหรือลด

🔧 เพิ่ม และ ลด แรงเสียดทาน

⬆️ เพิ่มแรงเสียดทาน

• ทำผิวให้ขรุขระ เช่น ดอกยางรถ

• พื้นกันลื่นในห้องน้ำ

• ใช้ยางหุ้มด้ามจับ

⬇️ ลดแรงเสียดทาน

• หยอด น้ำมันหล่อลื่น

• ใช้ ล้อ / ลูกปืน

• ทำผิวให้เรียบลื่น

👩‍🏫 สรุปบทเรียน ทบทวนแรง แรงลัพธ์ แรงเสียดทาน ให้นักเรียนช่วยกันพูด
สรุปบทเรียน หน่วยที่ 2 บทที่ 1

🎓 สรุป: แรงลัพธ์และแรงเสียดทาน

  • 💪แรง: ผลัก/ดึง มีขนาด+ทิศทาง วัดเป็นนิวตัน (N)
  • ➕ทิศเดียวกัน: แรงลัพธ์ = บวกกัน
  • ➖ทิศตรงข้าม: แรงลัพธ์ = ลบกัน (ไปทางแรงมากกว่า)
  • ⚖️แรงลัพธ์ = 0: วัตถุสมดุล อยู่นิ่ง
  • 🛑แรงเสียดทาน: ต้านการเคลื่อนที่ ขึ้นกับผิว+น้ำหนัก
