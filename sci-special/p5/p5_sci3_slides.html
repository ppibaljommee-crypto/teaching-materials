เสียงเกิดขึ้นได้อย่างไร?

เสียงเกิดจากการ สั่นสะเทือน ของวัตถุ
เมื่อวัตถุสั่น → อากาศรอบๆ สั่นตาม → เดินทางมาถึงหูเรา

✋ ลองพิสูจน์

• แตะคอแล้วพูด → รู้สึกสั่น

• ดีดสายยาง/สายกีตาร์ → เห็นสั่น

• เคาะส้อมเสียงแตะน้ำ → น้ำกระเซ็น

🔇 หยุดสั่น = หยุดเสียง

• จับสายกีตาร์ที่กำลังสั่นให้นิ่ง

• เสียงจะหายไปทันที

👩‍🏫 ให้นักเรียนยกตัวอย่างแหล่งกำเนิดเสียงรอบตัว แล้วชี้ว่าส่วนไหนสั่น

🎵 แหล่งกำเนิดเสียงรอบตัว

🎸 เครื่องดนตรี

สายสั่น / อากาศในท่อสั่น

🗣️ เสียงคน

เส้นเสียงในลำคอสั่น

🔔 กระดิ่ง/ระฆัง

โลหะสั่นเมื่อถูกเคาะ

📻 ลำโพง

แผ่นลำโพงสั่น

🐦 สัตว์

นก แมลง สั่นปีก/อวัยวะ

💨 ลม/ธรรมชาติ

อากาศสั่นผ่านสิ่งกีดขวาง

👩‍🏫 อธิบายการสั่นสะเทือนแทนด้วยคลื่น สั่นไป-มา รอบจุดสมดุล ครูสาธิตด้วยหนังยางหรือไม้บรรทัด

〰️ การสั่นสะเทือน → เสียง

〰️ การสั่นสะเทือนคืออะไร

• การเคลื่อนที่ไป-กลับ ซ้ำๆ รอบตำแหน่งเดิม

• ทำให้อากาศรอบๆ สั่นเป็น คลื่นเสียง

• คลื่นเดินทางมาถึงหูเรา

🔬 สังเกตได้อย่างไร

• วางเม็ดข้าวสาร/กระดาษบนลำโพง → เด้ง

• โรยทรายบนกลอง แล้วเคาะ → ทรายเต้น

• แสดงว่ามีการสั่นจริง

👩‍🏫 กิจกรรมที่ 1 (ชม.1): ให้นักเรียนทำให้เกิดเสียงด้วยของใกล้ตัว แล้วสังเกต/บันทึกว่าส่วนใดสั่น

กิจกรรม: เสียงกับการสั่น

📝 โจทย์

1. ทำให้เกิดเสียงจากของ 3 อย่าง (หนังยาง ไม้บรรทัด แก้วน้ำ ฯลฯ)
2. สังเกตว่าส่วนใดของวัตถุสั่น
3. ลองทำให้การสั่นหยุด แล้วบันทึกว่าเสียงเป็นอย่างไร
4. สรุป: เสียงเกิดและหยุดเพราะอะไร

👩‍🏫 เริ่ม ชม.2 ถามว่า "เสียงเดินทางมาถึงหูเราได้อย่างไร?" นำเข้าตัวกลาง
ชั่วโมงที่ 2 — เสียงกับตัวกลาง

📡 เสียงเคลื่อนที่ผ่าน "ตัวกลาง"

เสียงเดินทางจากแหล่งกำเนิดมาถึงหู ต้องอาศัย ตัวกลาง
ตัวกลางได้แก่ ของแข็ง ของเหลว และแก๊ส (อากาศ)

👩‍🏫 ยกตัวอย่างเสียงผ่านตัวกลางทั้ง 3 สถานะ ให้นักเรียนเล่าประสบการณ์ เช่น ได้ยินเสียงใต้น้ำ

🧊💧💨 เสียงผ่านตัวกลาง 3 สถานะ

🧊 ของแข็ง

แนบหูกับโต๊ะ
ได้ยินเสียงเคาะชัด

💧 ของเหลว

ได้ยินเสียงใต้น้ำ
เช่น ในสระว่ายน้ำ

💨 อากาศ

เสียงที่เราได้ยิน
ทั่วไปในชีวิตประจำวัน

👩‍🏫 เน้นว่าในสุญญากาศ (ไม่มีอากาศ) เสียงเดินทางไม่ได้ เช่น ในอวกาศเงียบสนิท

🚫 เสียงผ่าน "สุญญากาศ" ไม่ได้

🌌 ในอวกาศเงียบสนิท

• สุญญากาศ = ไม่มีอากาศ/ตัวกลาง

• ไม่มีอนุภาคให้สั่นต่อ

• เสียงจึงเดินทางไม่ได้

🔔 การทดลองคลาสสิก

• กระดิ่งในครอบแก้วที่ดูดอากาศออก

• ยิ่งดูดอากาศออก เสียงยิ่งเบาลง

• จนเงียบเมื่อเป็นสุญญากาศ

👩‍🏫 อธิบายว่าเสียงเดินทางในของแข็งเร็วที่สุด เพราะอนุภาคอยู่ชิดกัน ส่งต่อการสั่นได้เร็ว

🏃 เสียงเดินทางในตัวกลางใดเร็วสุด?

ของแข็ง > ของเหลว > อากาศ

• ของแข็ง อนุภาคชิดกันมาก → ส่งต่อการสั่นเร็วที่สุด

• ของเหลว อนุภาคชิดปานกลาง → เร็วปานกลาง

• อากาศ อนุภาคห่างกัน → ช้าที่สุด

💡 จึงแนบหูกับรางรถไฟ ได้ยินเสียงรถไฟก่อนได้ยินผ่านอากาศ

👩‍🏫 กิจกรรมที่ 2 (ชม.2): ทำโทรศัพท์กระป๋อง/แก้ว ต่อด้วยเชือก พิสูจน์ว่าเสียงผ่านของแข็ง (เชือก)
กิจกรรมที่ 2
📞

กิจกรรม: โทรศัพท์กระป๋อง

📝 โจทย์

1. ทำโทรศัพท์จากแก้ว/กระป๋อง 2 ใบ ต่อด้วยเชือก
2. ดึงเชือกให้ตึง แล้วพูดใส่ปลายหนึ่ง อีกคนฟังอีกปลาย
3. ลองหย่อนเชือก แล้วฟังอีกครั้ง
4. สรุป: เสียงเดินทางผ่านตัวกลางใด และตึง/หย่อนต่างกันอย่างไร

🎯 Quiz: เสียงเดินทางผ่านสิ่งใด "ไม่ได้"?

สุญญากาศไม่มีตัวกลาง (อนุภาค) ให้สั่นต่อ เสียงจึงเดินทางไม่ได้ ✅
👩‍🏫 เริ่ม ชม.3 แยกให้ชัดระหว่าง "สูง-ต่ำ" (ระดับเสียง) กับ "ดัง-ค่อย" (ความดัง) เด็กมักสับสน
ชั่วโมงที่ 3 — ลักษณะของเสียง

🎚️ เสียงสูง-ต่ำ และ ดัง-ค่อย

เสียงมี 2 ลักษณะที่ต่างกัน
สูง-ต่ำ (ระดับเสียง) และ ดัง-ค่อย (ความดัง)

⚠️ "เสียงสูง" ไม่ได้แปลว่า "เสียงดัง" — เป็นคนละเรื่องกัน

👩‍🏫 เสียงสูง-ต่ำ ขึ้นกับความถี่การสั่น สั่นเร็ว/ถี่ = สูง ครูสาธิตด้วยไม้บรรทัดยื่นสั้น-ยาว

🎵 เสียงสูง-ต่ำ (ระดับเสียง)

⬆️ เสียงสูง

• วัตถุสั่น เร็ว / ถี่ (ความถี่สูง)

• เช่น สายเส้นเล็ก/ตึง, ไม้บรรทัดยื่นสั้น

• เสียงนกหวีด เสียงเด็กเล็ก

⬇️ เสียงต่ำ

• วัตถุสั่น ช้า / ห่าง (ความถี่ต่ำ)

• เช่น สายเส้นใหญ่/หย่อน, ไม้บรรทัดยื่นยาว

• เสียงกลองใหญ่ เสียงผู้ชายทุ้ม

👩‍🏫 เสียงดัง-ค่อย ขึ้นกับพลังงาน/ขนาดการสั่น (แอมพลิจูด) เคาะแรง=ดัง หน่วยความดังคือเดซิเบล

🔊 เสียงดัง-ค่อย (ความดัง)

📢 เสียงดัง

• วัตถุสั่นด้วย พลังงานมาก (สั่นกว้าง)

• เคาะ/ดีด/ตีแรง

• เช่น ตีกลองแรงๆ

🔉 เสียงค่อย

• วัตถุสั่นด้วย พลังงานน้อย (สั่นแคบ)

• เคาะ/ดีด/ตีเบา

• หน่วยวัดความดัง = เดซิเบล (dB)

👩‍🏫 กิจกรรมที่ 3 (ชม.3): ใช้ไม้บรรทัด/หนังยาง ทดลองเปลี่ยนสูง-ต่ำ (ความยาว/ความตึง) และดัง-ค่อย (แรงดีด)
กิจกรรมที่ 3
📏

กิจกรรม: ทดลองเสียงสูง-ต่ำ ดัง-ค่อย

📝 โจทย์

1. กดไม้บรรทัดที่ขอบโต๊ะ ดีดให้สั่น — ลองยื่นสั้น/ยาว สังเกตเสียงสูง-ต่ำ
2. ดีดเบา/แรง สังเกตเสียงดัง-ค่อย
3. บันทึก: ยื่นสั้น → เสียง____ , ดีดแรง → เสียง____
4. สรุปความสัมพันธ์ของการสั่นกับเสียง

🎯 Quiz: ดีดสายกีตาร์เส้นเดิม "แรงขึ้น" เสียงจะเป็นอย่างไร?

ดีดแรงขึ้น = ให้พลังงานมาก → เสียง "ดัง" ขึ้น ส่วนสูง-ต่ำขึ้นกับความถี่ (ความตึง/ขนาดสาย) ✅
👩‍🏫 เริ่ม ชม.4 อธิบายเส้นทางการได้ยิน เสียง → ใบหู → แก้วหู → ส่งสัญญาณไปสมอง
ชั่วโมงที่ 4 — การได้ยิน

👂 เราได้ยินเสียงได้อย่างไร?

  • 1คลื่นเสียงเดินทางผ่านอากาศเข้าสู่ ใบหู
  • 2เสียงทำให้ แก้วหู สั่นสะเทือน
  • 3การสั่นถูกส่งต่อผ่านกระดูกหูชั้นกลาง
  • 4เปลี่ยนเป็นสัญญาณส่งไปยัง สมอง → แปลความเป็นเสียง
👩‍🏫 อภิปรายมลพิษทางเสียงในชีวิตจริง เช่น เสียงรถ เสียงก่อสร้าง หูฟังดังเกินไป และวิธีป้องกัน

🔇 มลพิษทางเสียง

⚠️ ผลเสีย

• เสียงดังเกิน 85 เดซิเบลนานๆ ทำลายการได้ยิน

• ทำให้เครียด หงุดหงิด นอนไม่หลับ

• เสียสมาธิ การเรียนแย่ลง

🛡️ การป้องกัน

• ไม่เปิดเพลง/หูฟังดังเกินไป

• ใส่ที่อุดหู/ครอบหูในที่เสียงดัง
