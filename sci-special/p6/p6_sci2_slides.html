การแยกสาร
เนื้อผสม

การกรอง • การระเหย • การตกตะกอน • การกลั่น

👩‍🏫 ถามนักเรียน "น้ำเกลือคือสารผสมหรือสารบริสุทธิ์?" ให้ถกกัน แล้วอธิบายความแตกต่าง
ชั่วโมงที่ 1

🔬 สารผสมคืออะไร?

สารผสม = สารตั้งแต่ 2 ชนิดขึ้นไปมาผสมกัน
โดยยังคงสมบัติเดิมของแต่ละสาร

🌊 สารเนื้อเดียว

ส่วนผสมเป็นเนื้อเดียวกัน

มองไม่เห็นแต่ละส่วน

• น้ำเกลือ • น้ำน้ำตาล

• น้ำส้มสายชู • อากาศ

🪨 สารเนื้อผสม

มองเห็นส่วนผสมแต่ละชนิด

แยกได้โดยใช้วิธีต่างๆ

• ทรายผสมน้ำ • น้ำผสมน้ำมัน

• ดินผสมกรวด • นมผสมโกโก้

👩‍🏫 ให้นักเรียนยกตัวอย่างสารเนื้อผสมในชีวิตประจำวันเพิ่มเติม เช่น น้ำปลา ซุปไก่ น้ำผลไม้ที่มีเนื้อ

🧩 ทำไมต้องแยกสาร?

  • 1กรองน้ำดื่มให้สะอาด ปลอดภัยจากสิ่งปนเปื้อน
  • 2ทำเกลือจากน้ำทะเล โดยการระเหยน้ำออก
  • 3แยกน้ำมันดิบเพื่อนำไปใช้ประโยชน์
  • 4ทำน้ำตาลทรายจากน้ำอ้อย
  • 5กรองทองจากทราย (ร่อนทอง)
👩‍🏫 สาธิตการกรองด้วยกระดาษกรองและกรวย ให้นักเรียนดูว่าสิ่งใดผ่านกระดาษกรองได้ สิ่งใดผ่านไม่ได้

🫙 วิธีที่ 1: การกรอง (Filtration)

ใช้แยก: ของแข็ง + ของเหลว

ของแข็งค้างอยู่บนกระดาษกรอง | ของเหลวไหลผ่านลงมา

🔬 วิธีการ

1. พับกระดาษกรองใส่กรวย

2. วางกรวยบนขวด/บีกเกอร์

3. เทสารผสมลงในกรวย

4. ของแข็งค้างบนกระดาษกรอง

5. ของเหลว (ตัวกรอง) ไหลลงมา

🌍 ตัวอย่างในชีวิต

• กรองน้ำประปาด้วยทราย

• กรองกาแฟด้วยกระดาษกรอง

• กรองน้ำต้มกระดูกเอาเศษกระดูกออก

• ไตกรองของเสียออกจากเลือด

👩‍🏫 สาธิตการระเหยน้ำเกลือในจานระเหย ให้นักเรียนสังเกตผลึกเกลือที่เหลือ

💨 วิธีที่ 2: การระเหย (Evaporation)

ใช้แยก: ของแข็งที่ละลายอยู่ในของเหลว

ให้ความร้อน → ของเหลวระเหยออก → ของแข็งเหลืออยู่

🔬 วิธีการ

1. เทสารละลายลงในจานระเหย

2. ให้ความร้อนจากตะเกียงแอลกอฮอล์

3. น้ำระเหยออกเป็นไอ

4. เกลือหรือสารละลายตกผลึก

🌍 ตัวอย่าง

• ทำนาเกลือจากน้ำทะเล

• ทำน้ำตาลจากน้ำอ้อย

• ทำผงกาแฟสำเร็จรูป

• ทำยาเม็ดจากสารละลาย

👩‍🏫 กิจกรรม 1.1: แยกทรายออกจากน้ำโดยการกรอง — เตรียมอุปกรณ์: บีกเกอร์ กรวย กระดาษกรอง ขาตั้ง น้ำผสมทราย
กิจกรรมที่ 1.1
🧫

กิจกรรม 1.1: แยกสารที่ผสมกันได้อย่างไร?

🔬 การทดลอง: กรองทรายออกจากน้ำ

วัสดุ: บีกเกอร์ กรวยแก้ว กระดาษกรอง ขาตั้ง น้ำผสมทราย

ขั้นตอน:
1. พับกระดาษกรองใส่กรวย → วางบนบีกเกอร์
2. เทน้ำผสมทรายลงในกรวยช้าๆ
3. สังเกตสิ่งที่ผ่านและไม่ผ่านกระดาษกรอง
4. บันทึกผลการทดลอง

👩‍🏫 สาธิตการตกตะกอน: เขย่าน้ำผสมดินแล้วทิ้งไว้ — สังเกตว่าดินค่อยๆ ตกลงมา ถามว่า "ใช้เวลานานไหม?"
ชั่วโมงที่ 2

⬇️ วิธีที่ 3: การตกตะกอน (Sedimentation)

ใช้แยก: ของแข็งที่ไม่ละลายน้ำ

ทิ้งไว้ให้อนุภาคหนักจมลงสู่ก้นภาชนะ

🔬 วิธีการ

1. เทสารผสมลงในภาชนะ

2. ทิ้งไว้ให้อนุภาคจมลง

3. ค่อยๆ เทของเหลวด้านบนออก

4. ได้ตะกอนอยู่ที่ก้น

🌍 ตัวอย่าง

• ทำน้ำประปา (ตกตะกอนก่อนกรอง)

• แยกทรายจากน้ำแม่น้ำ

• ทำน้ำซาวข้าว

• การทำเหมืองแร่

👩‍🏫 อธิบายการกลั่นด้วยภาพ เปรียบกับวัฏจักรน้ำ — น้ำระเหย → กลั่นตัว → หยดกลับลงมา

🌡️ วิธีที่ 4: การกลั่น (Distillation)

ใช้แยก: ของเหลวที่มีจุดเดือดต่างกัน

ต้ม → ไอระเหย → ทำให้เย็น → กลั่นตัวเป็นของเหลวบริสุทธิ์

🔬 หลักการ

• สารแต่ละชนิดมีจุดเดือดต่างกัน

• ให้ความร้อน → สารที่จุดเดือดต่ำระเหยก่อน

• ทำให้เย็น → ไอกลั่นตัวกลับ

• ได้สารบริสุทธิ์แยกออกมา

🌍 ตัวอย่าง

• กลั่นน้ำดื่มให้บริสุทธิ์

• กลั่นน้ำมันดิบ (โรงกลั่นน้ำมัน)

• กลั่นเหล้า/สุรา

• ทำน้ำหอม (กลั่นน้ำมันหอม)

👩‍🏫 สาธิตการร่อน: ใช้ตะแกรงแยกทรายกับกรวด ให้นักเรียนสังเกตหลักการ "ขนาดของอนุภาค"

🪣 วิธีที่ 5: การร่อน (Sieving)

ใช้แยก: ของแข็งที่มีขนาดต่างกัน

ใช้ตะแกรงหรือแร่งที่มีรูขนาดต่างกัน แยกอนุภาคตามขนาด

🔬 วิธีการ

• เลือกตะแกรงที่มีรูขนาดพอเหมาะ

• อนุภาคเล็กผ่านรูได้

• อนุภาคใหญ่ค้างอยู่บนตะแกรง

🌍 ตัวอย่าง

• ร่อนแป้งแยกก้อนแข็ง

• ร่อนทองจากทราย

• แยกดินและกรวด

• คัดขนาดผลไม้

👩‍🏫 สรุปเปรียบวิธีแยกสารทั้ง 5 วิธี ให้นักเรียนจับคู่สถานการณ์กับวิธีที่เหมาะสม

กิจกรรม 1.3: แยกของแข็งในของเหลว

🔬 การทดลอง: แยกน้ำมันออกจากน้ำ

วัสดุ: น้ำ น้ำมันพืช ขวดแก้ว ขาตั้งหยด

สังเกต:
1. เขย่าน้ำผสมน้ำมัน → รอสักครู่
2. น้ำมันอยู่ชั้นบน น้ำอยู่ชั้นล่าง (ทำไม?)
3. ใช้หลอดดูดหรือขาตั้งหยดแยกออกจากกัน
4. บันทึกและอธิบายว่าใช้หลักการใด

🌍 การแยกสารในชีวิตประจำวัน

  • 🚰โรงกรองน้ำประปา → ตกตะกอน + กรอง
  • 🧂การทำนาเกลือ → ระเหยน้ำออกด้วยแสงแดด
  • ⛽โรงกลั่นน้ำมัน → กลั่นแยกน้ำมันชนิดต่างๆ
  • ☕กาแฟดริป → กรองกากกาแฟออก
  • 🏗️แยกทรายและกรวด → ร่อนตามขนาด
