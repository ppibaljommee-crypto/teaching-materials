โจทย์ Pair Programming

📋 โจทย์: โปรแกรมคิดค่า BMI

1. รับน้ำหนัก (kg) และส่วนสูง (m) จากผู้ใช้
2. คำนวณ BMI = น้ำหนัก / (ส่วนสูง × ส่วนสูง)
3. แสดง BMI (ทศนิยม 2 ตำแหน่ง)
4. บอกผล: <18.5 = ผอม | 18.5-24.9 = ปกติ | ≥25 = น้ำหนักเกิน

👩‍🏫 เฉลยหลังจากทุกคู่ทำเสร็จ — ให้นักเรียนเปรียบเทียบโค้ดตัวเองกับเฉลย

✅ เฉลย: โปรแกรม BMI

bmi_calculator.py
# โปรแกรมคำนวณ BMI print("=== เครื่องคิด BMI ===") weight = float(input("น้ำหนัก (kg): ")) height = float(input("ส่วนสูง (m): ")) bmi = weight / (height ** 2) print(f"\nBMI ของคุณ: {bmi:.2f}") if bmi < 18.5: print("ผล: น้ำหนักน้อย (ผอม)") elif bmi <= 24.9: print("ผล: น้ำหนักปกติ ✅") else: print("ผล: น้ำหนักเกิน")

  • 🔄for = รู้รอบ | while = ไม่รู้รอบ
