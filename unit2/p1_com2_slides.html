🗺️ แป้นพิมพ์มี 4 โซนหลัก

  • 🔤โซนตัวอักษร — A ถึง Z อยู่ตรงกลาง พิมพ์คำ
  • 🔢โซนตัวเลข — 0-9 แถวบน และด้านขวา (Numpad)
  • ⚙️โซนปุ่มพิเศษ — Enter, Shift, Spacebar, Backspace
  • ⬆️โซนลูกศร — เลื่อนขึ้น ลง ซ้าย ขวา

🎨 ตกแต่งตัวอักษรใน Word

เปลี่ยนรูปแบบตัวอักษร

B Ctrl+B = ตัวหนา

I Ctrl+I = ตัวเอียง

U Ctrl+U = ขีดเส้นใต้

วิธีใช้

1. ลากเลือกข้อความก่อน

2. กดปุ่ม B / I / U บน Home

3. ข้อความจะเปลี่ยนทันที

• ฟอนต์ภาษาไทย: TH Sarabun

👩‍🏫 สาธิตปุ่มจัดข้อความ ชิดซ้าย กลาง ขวา

📐 จัดวางข้อความ

  • ⬅️ชิดซ้าย — ข้อความเริ่มจากซ้าย (Ctrl+L)
  • ↔️กึ่งกลาง — ข้อความอยู่กลางหน้า (Ctrl+E)
  • ➡️ชิดขวา — ข้อความชิดขวา (Ctrl+R)
💡 หัวข้อ/ชื่อเรื่อง นิยมจัดกึ่งกลาง ให้สวยงาม
👩‍🏫 สอนนักเรียนบันทึกไฟล์ในโฟลเดอร์ที่กำหนด — ตั้งชื่อไฟล์ให้เป็น

💾 การบันทึกไฟล์

  • 1กด Ctrl + S หรือไปที่ File → Save As
  • 2เลือก โฟลเดอร์ ที่ต้องการบันทึก
  • 3ตั้งชื่อไฟล์: ชื่อ_นามสกุล_ใบงาน
  • 4เลือกประเภท: Word Document (.docx)
  • 5กด Save
⚠️ พิมพ์ไปก็กด Ctrl+S บ่อยๆ กันงานหาย!
