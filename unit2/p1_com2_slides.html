📄 Microsoft Word คืออะไร?

Word = โปรแกรมพิมพ์เอกสารที่ใช้กันทั่วโลก
สร้างรายงาน จดหมาย ใบงาน ทำได้ง่ายๆ

ส่วนประกอบ Word

🔵 Title Bar — ชื่อไฟล์

🎨 Ribbon — เครื่องมือต่างๆ

📄 Document — พื้นที่พิมพ์

📊 Status Bar — ข้อมูลเอกสาร

แท็บสำคัญใน Ribbon

🏠 Home — ตัวอักษร ขนาด สี

📥 Insert — รูปภาพ ตาราง

📐 Layout — หน้ากระดาษ

💾 File → Save — บันทึก

👩‍🏫 ให้นักเรียนพิมพ์ตามที่สอน ตรวจดูท่าทางการพิมพ์

🎨 ตกแต่งข้อความใน Word

เปลี่ยนรูปแบบตัวอักษร

B Ctrl+B = ตัวหนา

I Ctrl+I = ตัวเอียง

U Ctrl+U = ขีดเส้นใต้

เปลี่ยนขนาดและสี

• ขนาดฟอนต์: 12, 14, 16, 24...

• ฟอนต์ภาษาไทย: TH Sarabun

• สีตัวอักษร: ปุ่ม A สีแดง

• Highlight: ปุ่มดินสอเน้นสี

👩‍🏫 สอนนักเรียนบันทึกไฟล์ในโฟลเดอร์ที่กำหนด — ตั้งชื่อไฟล์ให้เป็น

💾 การบันทึกไฟล์

  • 1กด Ctrl + S หรือไปที่ File → Save As
  • 2เลือก โฟลเดอร์ ที่ต้องการบันทึก
  • 3ตั้งชื่อไฟล์: ชื่อ_นามสกุล_ใบงาน
  • 4เลือกประเภท: Word Document (.docx)
  • 5กด Save
