Algorithm • Flowchart เบื้องต้น

👩‍🏫 ให้นักเรียนยกมือตอบ "หน่วยที่แล้วเรียนเรื่องอะไร?" ชมเชยทุกคนที่ตอบ
ชั่วโมงที่ 1

🔄 จำได้มั้ย? หน่วยที่ 1

  • 1เราเรียนเรื่อง ลองผิดลองถูก เราแก้ได้
  • 2เมื่อทำผิด → ไม่ต้องกลัว → ลองใหม่ได้เสมอ
  • 3การแก้ปัญหา = หาสาเหตุ แล้วแก้ให้ถูกจุด

หน่วยที่ 2 เราจะเรียนเรื่อง การเรียงขั้นตอน 📋

👩‍🏫 เกม "ครูสั่ง!" — ครูสั่งขั้นตอนเรียงกัน เช่น "ครูสั่งให้ยกมือซ้าย → ครูสั่งให้โบกมือ → ครูสั่งให้วางมือ" ถ้าทำสลับ = ผิด! ทำ 2-3 รอบ แล้วถามว่า "ทำไมต้องเรียงลำดับ?"
ชั่วโมงที่ 1 — กิจกรรม Warm-up
🎮

เกม "ครูสั่ง!" — ขั้นตอนห้ามสลับ

🟢 วิธีเล่น

ครูสั่งทีละขั้นตอน → นักเรียนทำตาม
ต้องทำตามลำดับเท่านั้น! ทำสลับ = แพ้

ตัวอย่าง: ยกมือ → โบก → วางลง → ปรบมือ

ถ้าสลับขั้นตอน → ผลลัพธ์เปลี่ยน! เหมือนกับ อัลกอริทึม

👩‍🏫 อธิบายง่ายๆ ว่า Algorithm = สูตรสำเร็จ / ขั้นตอนที่ชัดเจน ทำซ้ำได้

📋 อัลกอริทึมคืออะไร?

อัลกอริทึม (Algorithm) = ขั้นตอนที่ชัดเจน
ทำทีละขั้น ครบแล้วได้ผลลัพธ์ที่ต้องการ

🌟 ตัวอย่างในชีวิตประจำวัน

• สูตรอาหาร → ทำตามขั้นตอน → ได้อาหาร

• แผนที่ → เดินตามทาง → ถึงจุดหมาย

• กฎเกม → เล่นตามกฎ → ชนะหรือแพ้

✅ อัลกอริทึมที่ดีต้องมี

• ชัดเจน ไม่คลุมเครือ

• มีจุดเริ่มต้นและสิ้นสุด

• ทำซ้ำได้ ได้ผลเหมือนกัน

• ทุกคนอ่านแล้วเข้าใจตรงกัน

👩‍🏫 ให้นักเรียนลองบอกขั้นตอนการแปรงฟันก่อน แล้วค่อยแสดงสไลด์ — ถามว่า "ถ้าทำสลับข้อ 2 กับข้อ 3 จะเกิดอะไร?"

🦷 ขั้นตอนการแปรงฟัน

  • 1หยิบแปรงสีฟัน
  • 2บีบยาสีฟันลงบนแปรง
  • 3เปิดน้ำ — เปียกแปรง
  • 4แปรงฟัน 2 นาที (ทุกซี่)
  • 5บ้วนปาก — ล้างแปรง — เก็บแปรง

ถ้าทำไม่ครบขั้นตอน หรือทำสลับลำดับ → ผลลัพธ์จะเปลี่ยน!

👩‍🏫 ให้นักเรียนช่วยกันบอกขั้นตอน แล้วครูเขียนบนกระดาน — รับฟังทุกคำตอบ บางขั้นตอนอาจสลับกันได้ก็ไม่เป็นไร ให้อภิปรายร่วมกัน

👟 ฝึกบอกขั้นตอน: ใส่รองเท้า

🙋 นักเรียนช่วยกันบอก!

ขั้นตอนการใส่รองเท้ามีอะไรบ้าง?
ใครรู้บ้างลองยกมือตอบ

1. หยิบถุงเท้า → 2. ใส่ถุงเท้าทั้งสองข้าง → 3. หยิบรองเท้า → 4. สวมรองเท้า → 5. ผูกเชือก (หรือล็อกตีนตุ๊กแก)
👩‍🏫 ให้นักเรียนช่วยกันบอกว่าขั้นตอนไหนมาก่อน ใช้เป็นกิจกรรมกลุ่ม ชมเชยเมื่อตอบถูก

🎮 เรียงขั้นตอน: ชงโอวัลติน

ขั้นตอนไหนมาก่อน? ช่วยกันเรียง!

🥄 ใส่โอวัลติน  |  🫖 เทน้ำร้อน  |  ☕ คนให้เข้ากัน  |  🥛 เทนมลงแก้ว

✅ เทนมลงแก้ว → ใส่โอวัลติน → เทน้ำร้อน → คนให้เข้ากัน
👩‍🏫 โจทย์นี้ยากขึ้นหน่อย — อาจมีคำตอบได้หลายแบบ ให้นักเรียนอภิปรายกัน "ทำไมต้องเอาตารางเรียนก่อน?" ไม่มีคำตอบถูกหรือผิดชัดเจน ฝึกการคิด
ชั่วโมงที่ 2

🎒 เรียงขั้นตอน: ใส่กระเป๋านักเรียน

ขั้นตอนไหนมาก่อน?

📒 ใส่สมุด  |  📅 ดูตารางเรียน  |  🎒 ปิดกระเป๋า  |  ✏️ ใส่ดินสอ  |  📚 เอาหนังสือที่ต้องใช้

✅ ดูตารางเรียน → เอาหนังสือที่ต้องใช้ → ใส่สมุด → ใส่ดินสอ → ปิดกระเป๋า
👩‍🏫 บอกว่า Flowchart คือ "ภาพ" ของอัลกอริทึม ทำให้เห็นได้ง่ายขึ้น ให้นักเรียนบอกว่าชอบแบบไหนมากกว่ากัน
