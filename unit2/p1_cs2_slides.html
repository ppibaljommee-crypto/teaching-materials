Algorithm • Flowchart เบื้องต้น

👩‍🏫 ทบทวน: "หน่วยที่แล้วเราเรียนเรื่องอะไร?" — ลองผิดลองถูก แก้ปัญหาได้

🔄 จำได้มั้ย? หน่วยที่ 1

  • 1เราเรียนเรื่อง ลองผิดลองถูก เราแก้ได้
  • 2เมื่อทำผิด → ไม่ต้องกลัว → ลองใหม่ได้เสมอ
  • 3การแก้ปัญหา = หาสาเหตุ แล้วแก้ให้ถูกจุด

หน่วยที่ 2 เราจะเรียนเรื่อง การเรียงขั้นตอน 📋

👩‍🏫 อธิบายง่ายๆ ว่า Algorithm = สูตรสำเร็จ / ขั้นตอนที่ชัดเจน

📋 อัลกอริทึมคืออะไร?

อัลกอริทึม (Algorithm) = ขั้นตอนที่ชัดเจน
ทำทีละขั้น ครบแล้วได้ผลลัพธ์ที่ต้องการ

🌟 ตัวอย่างในชีวิตประจำวัน

• สูตรอาหาร → ทำตามขั้นตอน → ได้อาหาร

• แผนที่ → เดินตามทาง → ถึงจุดหมาย

• กฎเกม → เล่นตามกฎ → ชนะหรือแพ้

✅ อัลกอริทึมที่ดีต้องมี

• ชัดเจน ไม่คลุมเครือ

• มีจุดเริ่มต้นและสิ้นสุด

• ทำซ้ำได้ ได้ผลเหมือนกัน

• ทุกคนอ่านแล้วเข้าใจตรงกัน

👩‍🏫 ให้นักเรียนลองบอกขั้นตอนการแปรงฟันก่อน แล้วค่อยแสดงสไลด์

🦷 ขั้นตอนการแปรงฟัน

  • 1หยิบแปรงสีฟัน
  • 2บีบยาสีฟันลงบนแปรง
  • 3เปิดน้ำ — เปียกแปรง
  • 4แปรงฟัน 2 นาที (ทุกซี่)
  • 5บ้วนปาก — ล้างแปรง — เก็บแปรง

ถ้าทำไม่ครบขั้นตอน หรือทำสลับลำดับ → ผลลัพธ์จะเปลี่ยน!

👩‍🏫 ให้นักเรียนช่วยกันบอกว่าขั้นตอนไหนมาก่อน — ใช้เป็นกิจกรรมกลุ่ม

🎮 ลองเรียงขั้นตอนกัน!

การชงโอวัลติน ขั้นตอนไหนมาก่อน?

🥄 ใส่โอวัลติน  |  🫖 เทน้ำร้อน  |  ☕ คนให้เข้ากัน  |  🥛 เทนมลงแก้ว

✅ เทนมลงแก้ว → ใส่โอวัลติน → เทน้ำร้อน → คนให้เข้ากัน
👩‍🏫 บอกว่า Flowchart คือ "ภาพ" ของอัลกอริทึม ทำให้เห็นได้ง่ายขึ้น

📊 Flowchart คืออะไร?

Flowchart = แผนภาพแสดงขั้นตอน
ใช้รูปร่างและลูกศรแทนคำอธิบาย

🔵 แบบอัลกอริทึม (ข้อความ)

1. ตื่นนอน
2. ล้างหน้า
3. กินข้าวเช้า
4. ออกไปโรงเรียน

🟡 แบบ Flowchart (ภาพ)

ตื่นนอน
↓
ล้างหน้า
↓
กินข้าวเช้า
↓
ออกไปโรงเรียน
👩‍🏫 ให้นักเรียนวาดสัญลักษณ์แต่ละอันลงสมุดพร้อมความหมาย

🔷 สัญลักษณ์ Flowchart ที่ต้องรู้

วงรี

= เริ่มต้น / สิ้นสุด

สี่เหลี่ยม

= ขั้นตอน / การกระทำ

→ ↓

= ลูกศร / ทิศทาง

💡 จำง่ายๆ ว่า

• วงรี = ต้นทางกับปลายทาง

• สี่เหลี่ยม = สิ่งที่ต้องทำ

• ลูกศร = บอกว่าไปต่อที่ไหน


ใน ป.1 เราใช้แค่ 3 อัน นี้ก่อน! 🎉

👩‍🏫 แจกใบงาน Flowchart "เช้าวันเรียนของฉัน" ให้นักเรียนวาดเอง
✍️

งานของเรา: Flowchart เช้าวันเรียน

📋 โจทย์

วาด Flowchart แสดงขั้นตอนที่ทำตั้งแต่ ตื่นนอน จนถึง เข้าห้องเรียน
ต้องมีอย่างน้อย 5 ขั้นตอน

ใช้ วงรี (เริ่ม/จบ) • สี่เหลี่ยม (ขั้นตอน) • ลูกศร (ทิศทาง)

👩‍🏫 สุ่มนักเรียน 3-4 คนออกมานำเสนอ Flowchart ของตัวเอง

🌟 ตัวอย่าง Flowchart ที่ดี

✅ ต้องมี

• วงรีที่ต้น (เริ่มต้น)

• วงรีที่ท้าย (สิ้นสุด)

• สี่เหลี่ยมทุกขั้นตอน

• ลูกศรเชื่อมทุกกล่อง

• อ่านจากบนลงล่าง

❌ ห้ามลืม

• ลืมลูกศร

• ไม่มีจุดเริ่มต้น

• ไม่มีจุดสิ้นสุด

• ขั้นตอนน้อยกว่า 5 ขั้น

• เขียนแน่นจนอ่านไม่ออก

👩‍🏫 สรุปบทเรียน ให้นักเรียนท่องความหมายของสัญลักษณ์
