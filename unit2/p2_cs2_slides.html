🔄 Loop คือการวนซ้ำ

Loop = ทำซ้ำบางอย่างจนกว่าจะพอ
หรือจนกว่าเงื่อนไขจะเป็นจริง

🌍 ตัวอย่างในชีวิต

• ซักผ้า → ล้างซ้ำ 3 รอบ

• เช็ดกระดาน → เช็ดซ้ำจนสะอาด

• ออกกำลังกาย → วิ่ง 5 รอบ

• กินยา → กิน 3 วัน เช้า-เย็น

💻 Loop ในคอมพิวเตอร์

โปรแกรมสามารถสั่งให้

เช่น ดูวิดีโอ → เล่นต่อ → เล่นต่อ
จนกว่าจะกด หยุด

งาน: วาด Flowchart ที่มี Loop

📋 โจทย์

วาด Flowchart สำหรับ "ดูแลต้นไม้ 5 วัน"
ต้อง: รดน้ำทุกวัน → ตรวจสอบ → วนซ้ำจน 5 วัน

ต้องมี รูปเพชร (เงื่อนไข) + ลูกศรย้อนกลับ (Loop)

👩‍🏫 สุ่มนักเรียน 3 คนออกมาอธิบาย Flowchart ของตัวเอง

✅ เกณฑ์ตรวจ Flowchart ที่ดี

ต้องมีทั้งหมดนี้

✅ วงรี เริ่ม / สิ้นสุด

✅ สี่เหลี่ยมทุกขั้นตอน

✅ รูปเพชร (เงื่อนไข Loop)

✅ ลูกศรย้อนกลับ

✅ ลูกศร "ออก" จาก Loop เมื่อครบ

ข้อผิดพลาดที่พบบ่อย

❌ ไม่มีรูปเพชร

❌ ลูกศรย้อนกลับไม่มี

❌ Loop ไม่มีทางออก

❌ ลืมตัวนับ / เงื่อนไขหยุด

👩‍🏫 สรุปบทเรียน ถามอีกครั้งว่า Loop คืออะไร
