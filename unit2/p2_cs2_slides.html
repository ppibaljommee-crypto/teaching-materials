🎮

เกม "ทำซ้ำ!" — Loop ในชีวิตจริง

🟢 วิธีเล่น

ครูสั่ง → นักเรียนทำตามจำนวนที่บอก

"โบกมือ 3 ครั้ง!" → ทำ 3 ครั้ง
"กระโดด 5 ครั้ง!" → ทำ 5 ครั้ง
"ปรบมือจนครูบอกหยุด!" → ทำจนหยุด

การทำซ้ำตามจำนวน = Loop ที่มีเงื่อนไข

👩‍🏫 ทบทวนสัญลักษณ์เดิมจาก ป.1 ก่อน แล้วเพิ่มรูปเพชร — ให้นักเรียนวาดลงสมุด

🔷 สัญลักษณ์ Flowchart ทั้งหมด

รู้จักแล้ว (ป.1)

⬭ วงรี = เริ่ม / สิ้นสุด

▭ สี่เหลี่ยม = ขั้นตอน

→ ลูกศร = ทิศทาง

🆕 หน่วยนี้เพิ่ม!

◇ รูปเพชร = เงื่อนไข

ใช่ / ไม่ใช่ (Yes/No)

รูปเพชร + ลูกศรย้อนกลับ = Loop!

👩‍🏫 ยกตัวอย่าง Loop ในชีวิต: "ซักผ้า 3 รอบ" "เช็ดกระดานจนสะอาด" "วิ่ง 5 รอบ" ให้นักเรียนช่วยคิดเพิ่ม

🔄 Loop = การวนซ้ำ

Loop = ทำซ้ำบางอย่างจนครบจำนวน
หรือจนกว่าเงื่อนไขจะเป็นจริง

🌍 ตัวอย่างในชีวิต

• ซักผ้า → ล้างซ้ำ 3 รอบ

• เช็ดกระดาน → เช็ดซ้ำจนสะอาด

• ออกกำลังกาย → วิ่ง 5 รอบ

• กินยา → กิน 3 วัน เช้า-เย็น

💻 Loop ในคอมพิวเตอร์

โปรแกรมสั่งให้ทำสิ่งเดิมซ้ำๆ

โดยอัตโนมัติ ไม่ต้องสั่งทุกครั้ง

เช่น ดูวิดีโอ → เล่นต่อ → เล่นต่อ
จนกว่าจะกด หยุด

👩‍🏫 กดปุ่ม "+1 วน Loop" ให้นักเรียนดู — ถามว่า "ถ้า Loop ไม่มีเงื่อนไขหยุด จะเกิดอะไร?"

✏️ ฝึก Trace เอง

📋 โจทย์: Trace Flowchart ล้างถ้วย

ใน Flowchart หน้าก่อน ถ้าเริ่ม ตัวนับ = 0
เติมตารางในสมุดของตัวเอง

ตารางที่ต้องเติม

รอบที่ 1: ตัวนับ = ? → ล้างถ้วย → ตัวนับ = ?

รอบที่ 2: ตัวนับ = ? → ล้างถ้วย → ตัวนับ = ?

รอบที่ 3: ตัวนับ = ? → ล้างถ้วย → ตัวนับ = ?

รอบที่ 4: ตรวจ → Loop หยุดเพราะอะไร?

คำถามเพิ่มเติม

• ล้างถ้วยรวมกี่ใบ?

• ถ้าเปลี่ยนเงื่อนไขเป็น < 5
จะล้างถ้วยกี่ใบ?

• ถ้าไม่มีรูปเพชรเลย
Flowchart จะทำงานได้ไหม?

รอบ1: 0→ล้าง→1 | รอบ2: 1→ล้าง→2 | รอบ3: 2→ล้าง→3 | หยุดเพราะ 3 ไม่ < 3 | รวม 3 ใบ
👩‍🏫 Quiz 3 ข้อ — ทำทีละข้อ ให้ตอบพร้อมกัน "ยกนิ้วโป้ง=A, กำมือ=B, ยกมือ=C"
ชั่วโมงที่ 2 — ทดสอบ (1/3)

🎯 Quiz ข้อ 1

ชั่วโมงที่ 2 — ทดสอบ (2/3)

🎯 Quiz ข้อ 2

Loop ที่ดีต้องมีอะไรเสมอ เพื่อไม่ให้วนไม่หยุด?

👩‍🏫 ข้อนี้ต้อง trace ก่อนตอบ — ให้เวลา 1 นาทีก่อนเฉลย
ชั่วโมงที่ 2 — ทดสอบ (3/3)

🎯 Quiz ข้อ 3

Flowchart วน Loop โดย: เริ่มที่ n=1, เพิ่มทีละ 1, หยุดเมื่อ n > 3
Loop จะทำงานทั้งหมดกี่ครั้ง?

n=1: 1>3? ไม่ → ทำ → n=2 | n=2: 2>3? ไม่ → ทำ → n=3 | n=3: 3>3? ไม่ → ทำ → n=4 | n=4: 4>3? ใช่ → หยุด ✅ รวม 3 ครั้ง
👩‍🏫 แจกใบงาน 2.1 ให้นักเรียนวาด Flowchart ที่มี Loop อย่างน้อย 1 จุด เดินดูงาน ชมเชยทุกคน
ชั่วโมงที่ 3 — ใบงาน
✍️

ใบงาน: วาด Flowchart ที่มี Loop

📋 โจทย์

วาด Flowchart สำหรับ "ดูแลต้นไม้ 5 วัน"
รดน้ำทุกวัน → ตรวจสอบ → วนซ้ำจน 5 วัน
ต้องมี รูปเพชร (เงื่อนไข) + ลูกศรย้อนกลับ (Loop)

👩‍🏫 แบ่งกลุ่ม 3-4 คน เลือกหัวข้อ วาด Flowchart ที่มี Loop ร่วมกัน — เดินดูทุกกลุ่ม ถามว่าเงื่อนไขหยุดคืออะไร
ชั่วโมงที่ 3 — กิจกรรมกลุ่ม

👥 กลุ่ม: Flowchart Loop ของเรา

ต้องมี Loop ที่มีเงื่อนไขหยุดชัดเจน!

บัตรออกห้อง (Exit Ticket)

✍️ เขียนในกระดาษแผ่นเล็ก แล้วส่งครู

วาด Flowchart Loop ง่ายๆ 1 อัน
เรื่องอะไรก็ได้ที่มี Loop ในชีวิตประจำวัน
(ต้องมี วงรีเริ่ม → รูปเพชร → สี่เหลี่ยม → ลูกศรย้อนกลับ → วงรีจบ)

ครูจะนำไปดูว่าเข้าใจ Loop แล้วหรือยัง

👩‍🏫 สุ่ม 2-3 กลุ่มออกมานำเสนอ Flowchart — ให้อธิบายว่า Loop วนกี่ครั้ง เงื่อนไขหยุดคืออะไร
