วันนี้เราจะเรียน If-Then-Else ใน Flowchart

👩‍🏫 เกม "ตัดสินใจ!" — ครูบอกสถานการณ์ นักเรียนยกมือซ้าย=ทำ A, ยกมือขวา=ทำ B เล่น 4-5 สถานการณ์ แล้วถามว่า "นี่คือ If-Then-Else ในชีวิตจริง!"
ชั่วโมงที่ 1 — Warm-up
🤔

เกม "ตัดสินใจ!"

🟢 วิธีเล่น: ยกมือซ้าย = ทำ A | ยกมือขวา = ทำ B

ถ้าฝนตก → A: เอาร่ม | B: ไม่เอา
ถ้าหิว → A: กินข้าว | B: ดื่มน้ำ
ถ้าบ้านไกล → A: รถโรงเรียน | B: เดิน
ถ้าสอบผ่าน → A: ฉลอง | B: อ่านหนังสือเพิ่ม

การตัดสินใจแบบ "ถ้า...ทำ...ถ้าไม่...ทำอีกอย่าง" = If-Then-Else!

👩‍🏫 ให้นักเรียนยกตัวอย่างเงื่อนไขในชีวิตประจำวันเพิ่มเติม — รับฟังทุกคำตอบ

🤔 เงื่อนไขในชีวิตประจำวัน

🌧️ ตัวอย่าง

• ถ้าฝนตก → เอาร่ม ถ้าไม่ตก → ไม่เอา

• ถ้าหิว → กินข้าว ถ้าไม่หิว → ดื่มน้ำ

• ถ้าคะแนนผ่าน → ได้ A ถ้าไม่ผ่าน → สอบซ่อม

💡 สูตรเงื่อนไข

ถ้า [เงื่อนไข]
  → ทำ A
ถ้าไม่
  → ทำ B

👩‍🏫 อธิบาย If-Then-Else เทียบกับชีวิตประจำวัน — ชี้รูปเพชรในแผนภาพ

🔀 If – Then – Else คืออะไร?

IF (เงื่อนไข) THEN (ทำสิ่งนี้) ELSE (ถ้าไม่ใช่ทำอีกอย่าง)

👩‍🏫 อธิบายว่า Flowchart สามารถมีรูปเพชรหลายอัน (ซ้อนกัน) ได้ เหมือนการตัดสินใจหลายชั้น

🎯 เงื่อนไขซ้อนกัน (Nested If)

โปรแกรมให้เกรด

ถ้า คะแนน ≥ 80 → เกรด A

ถ้าไม่ใช่ และ ≥ 70 → เกรด B

ถ้าไม่ใช่ และ ≥ 60 → เกรด C

ถ้าไม่ใช่ → เกรด F (ต้องเรียนซ่อม)

ใน Flowchart เดียวมีรูปเพชรได้ หลายอัน!

👩‍🏫 ให้นักเรียน trace ทีละขั้น บนกระดาน — "ถ้าคะแนน 55 จะเดินทางไหน?"

🔍 Trace: ถ้าได้คะแนน 75 ได้เกรดอะไร?

→ เริ่มต้น: คะแนน = 75

→ ตรวจ: 75 ≥ 80? → ไม่ใช่

→ ตรวจ: 75 ≥ 70? → ใช่!

→ ผลลัพธ์: เกรด B

🎓 ได้เกรด B เพราะ 75 ≥ 70 แต่ไม่ถึง 80
👩‍🏫 ให้นักเรียนเขียนในสมุด — trace เองทีละขั้นสำหรับทั้ง 3 คะแนน ไม่คุยกับเพื่อน

✏️ ฝึก Trace: ระบบให้เกรด

📋 โจทย์: trace สำหรับคะแนนต่อไปนี้

ใช้กฎ: ≥80=A, ≥70=B, ≥60=C, อื่นๆ=F
เขียน trace ในสมุดว่าแต่ละคะแนนได้เกรดอะไร

Trace คะแนนเหล่านี้

• คะแนน = 85 → เกรด ?

• คะแนน = 68 → เกรด ?

• คะแนน = 55 → เกรด ?

คำถามเพิ่มเติม

• คะแนน 70 กับ 79 ได้เกรดเดียวกันไหม?

• ถ้าอยากได้เกรด A ต้องทำคะแนนอย่างน้อยเท่าไร?

85→A | 68→C | 55→F | คะแนน 70-79 ได้เกรด B เหมือนกัน | ต้อง ≥ 80 ได้เกรด A
👩‍🏫 Quiz 3 ข้อ — ให้ตอบพร้อมกัน "ยกนิ้วโป้ง=A, กำมือ=B, ยกมือ=C, สองมือ=D"
ชั่วโมงที่ 2 — ทดสอบ (1/3)

ชั่วโมงที่ 3 — ใบงาน
✍️

ใบงาน: วาด Flowchart If-Then-Else

📋 โจทย์

วาด Flowchart สำหรับ "การเลือกดูหนัง"
ถ้าหนังเรต ผู้ใหญ่ → ดูกับพ่อแม่ | ถ้าเรต ทั่วไป → ดูคนเดียวได้
ต้องมี รูปเพชร + 2 ทางออก (Yes/No) + วงรีเริ่ม/จบ

👩‍🏫 แบ่งกลุ่ม 3-4 คน เลือก 1 หัวข้อ วาด Flowchart If-Then-Else ร่วมกัน ขนาดใหญ่บนกระดาษ A4
ชั่วโมงที่ 3 — กิจกรรมกลุ่ม

ต้องมีรูปเพชรและ 2 ทางออก Yes/No ที่ชัดเจน!

🌟 หัวข้อให้เลือก

• 🌦️ ตัดสินใจว่าจะเล่นนอกบ้านไหม

• 🍕 เลือกว่าจะกินอะไรตอนกลางวัน

• 🎮 ตัดสินใจว่าจะเล่นเกมหรืออ่านหนังสือ

• 🐶 ดูแลสัตว์เลี้ยง ถ้าป่วยทำอะไร

✅ ต้องมีครบ

• รูปเพชร (เงื่อนไข)

• ชื่อสมาชิกกลุ่มทุกคน

👩‍🏫 ส่ง Flowchart ให้กลุ่มข้างๆ ตรวจ ฝึกการให้ feedback สร้างสรรค์

บัตรออกห้อง (Exit Ticket)

✍️ เขียนในกระดาษแผ่นเล็ก แล้วส่งครู

วาด Flowchart If-Then-Else ง่ายๆ
เงื่อนไขเรื่องอะไรก็ได้ในชีวิตประจำวัน
(ต้องมี วงรีเริ่ม → รูปเพชร → สาขา Yes/No → วงรีจบ)

ครูจะตรวจว่าเข้าใจ If-Then-Else แล้วหรือยัง

👩‍🏫 สรุปบทเรียน ย้ำว่ารูปเพชรสร้าง "การตัดสินใจ" ใน Flowchart

🎓 สรุป: Flowchart มีเงื่อนไข

  • ◇รูปเพชร = เงื่อนไข (Condition)
  • ✅ทางออก ใช่ (Yes) → ทำอย่างนี้
  • ❌ทางออก ไม่ใช่ (No) → ทำอีกอย่าง
  • 🔀If-Then-Else = โครงสร้างเงื่อนไขพื้นฐาน
  • 🧩มีรูปเพชรได้หลายอันในหนึ่ง Flowchart
