👩‍🏫 อธิบายว่ากราฟแต่ละแบบใช้กับข้อมูลประเภทไหน

📊 ประเภทกราฟที่ควรรู้

📊 Bar Chart (กราฟแท่ง)

• เปรียบเทียบค่าหลายๆ กลุ่ม

• เช่น คะแนนแต่ละวิชา

▌▌▌ ง่ายที่สุด เหมาะกับ ป.6

🥧 Pie Chart (กราฟวงกลม)

• แสดงสัดส่วน/เปอร์เซ็นต์

• เช่น % ชอบวิชาอะไร

🍕 ผลรวม = 100%

📈 Line Chart (กราฟเส้น)

• แสดงแนวโน้มตามเวลา

• เช่น คะแนนรายเดือน

📉 เห็นการเปลี่ยนแปลง

🖼️ Infographic

• กราฟ + รูปภาพ + ข้อความ

• สวยงาม แชร์โซเชียลได้

🎨 ดูแล้วอยากอ่าน!

👩‍🏫 ยกตัวอย่างข้อมูลแล้วให้นักเรียนช่วยเลือกกราฟ

🎯 เลือกกราฟให้ตรงกับข้อมูล

  • 📊เปรียบเทียบจำนวน/กลุ่ม → Bar Chart
  • 🥧สัดส่วน % ของทั้งหมด → Pie Chart
  • 📈แนวโน้มตามเวลา → Line Chart
  • 🔗ความสัมพันธ์/ขั้นตอน → SmartArt
💡 เลือกกราฟผิดประเภท จะทำให้คนอ่านเข้าใจข้อมูลผิดได้
👩‍🏫 สาธิตการทำ tally แบบนับขีด ก่อนแปลงเป็นตัวเลข

📋 ขั้นแรก: เก็บและจัดระเบียบข้อมูล

วิธีเก็บข้อมูล

• ตั้งคำถามสำรวจให้ชัด

• นับด้วย ขีดคะแนน (Tally)

• เช่น 🍕 //// = 4 คน

จัดเป็นตาราง

• ใส่ลงตารางใน Excel/Word

• คอลัมน์: หัวข้อ + จำนวน

• ตรวจผลรวมให้ถูกต้อง

👩‍🏫 Demo สร้างกราฟใน Canva: Elements → ค้นหา "Charts" → เลือกแบบ → แก้ข้อมูล

🛠️ สร้างกราฟใน Canva

  • 1แถบซ้าย → Elements
  • 2พิมพ์ค้น "Charts" เลือกแบบ (Bar / Pie / Line)
  • 3คลิกกราฟ → ปุ่ม "Edit" (แก้ไขข้อมูล)
  • 4กรอกตัวเลขในตารางขวา — กราฟอัปเดตทันที
  • 5เปลี่ยนสี ชื่อกราฟ และฟอนต์ให้เข้าธีม
👩‍🏫 Demo ใน Canva: เปิด Data labels, เปลี่ยน Color, เพิ่มกล่องข้อความเป็นชื่อกราฟ

🔧 ปรับแต่งกราฟให้อ่านง่าย

ใส่รายละเอียด

• ชื่อกราฟ — เพิ่มกล่อง Text ด้านบน

• Data labels — เปิดให้โชว์ตัวเลข

• Legend — คำอธิบายสี

ทำให้สวยงาม

• Color — เปลี่ยนชุดสีกราฟ

• เลือกสีให้เข้าธีม 3 สี

• แก้ตัวเลข: กดปุ่ม Edit

👩‍🏫 เปรียบเทียบ Infographic ที่รกกับที่โล่งสบายตา

🎨 หลักการออกแบบให้ดูดี

✅ ควรทำ

• เว้นที่ว่างให้หายใจ

• เรียงลำดับจากบนลงล่าง

• เน้นตัวเลขสำคัญให้ใหญ่

• ใช้ฟอนต์อ่านง่าย

❌ ควรเลี่ยง

• ยัดข้อมูลแน่นเกินไป

• ใช้สีฉูดฉาดเยอะเกิน

• ฟอนต์หลายแบบปนกัน

• รูปเบลอ/ความละเอียดต่ำ

👩‍🏫 Demo Canva: Elements → ค้นหา "diagram / process / cycle"

🎨 กราฟิกแสดงความสัมพันธ์ (Elements)

หาได้จากไหน?

• Elements → ค้นหา "diagram"

• กราฟิกสำเร็จรูปแบบมีโครงสร้าง

• ปรับสีและข้อความได้

คำค้นที่ควรรู้

📋 List — รายการ

🔄 Process — ขั้นตอน

🔵 Cycle — วงจร

🌲 Hierarchy — ลำดับขั้น

👩‍🏫 Demo Canva: Elements → พิมพ์ค้นไอคอน เช่น "apple" แล้วลากวาง

🔣 ใช้ไอคอนเล่าข้อมูล

  • 1Elements → พิมพ์ค้น ชื่อไอคอน (ภาษาอังกฤษ)
  • 2ใช้ไอคอนแทนหัวข้อ เช่น 🍎 = อาหาร
  • 3ไอคอนสไตล์เดียวกัน = ดูเป็นชุดเดียวกัน
  • 4คลิกไอคอน → เปลี่ยนสีให้เข้าธีมได้
💡 ไอคอนช่วยให้ผู้อ่านเข้าใจได้เร็ว โดยไม่ต้องอ่านข้อความเยอะ
👩‍🏫 อธิบายเรื่อง contrast — พื้นเข้มตัวอ่อน พื้นอ่อนตัวเข้ม

🌈 สีและความคมชัด (Contrast)

เลือกคู่สี

• ใช้สีหลัก 2-3 สี

• พื้นหลังเข้ม → ตัวอักษรสว่าง

• พื้นหลังสว่าง → ตัวอักษรเข้ม

เน้นข้อมูลสำคัญ

• ใช้ สีเด่น 1 สีไฮไลต์

• ตัวเลขสำคัญ = ตัวใหญ่ สีต่าง

• อย่าใช้สีอ่อนบนพื้นอ่อน

👩‍🏫 แนะนำการจัดวาง Infographic 1 หน้า จากบนลงล่าง

🗂️ โครงสร้าง Infographic ที่แนะนำ (บน→ล่าง)

  • 1หัวเรื่อง — ชื่อเรื่องตัวใหญ่ สะดุดตา
  • 2ที่มา — เราสำรวจอะไร จากใคร
  • 3กราฟ + ไอคอน — ส่วนหลักของข้อมูล
  • 4ตัวเลขเด่น — ไฮไลต์ข้อมูลสำคัญ
  • 5สรุป + อ้างอิง — สิ่งที่ค้นพบ + แหล่งข้อมูล
👩‍🏫 Demo Canva: Share → Download → PNG/PDF และการแชร์ลิงก์

💾 บันทึกและส่งงาน Canva

  • 1มุมขวาบน → Share
  • 2Download → เลือก PNG (รูป) หรือ PDF
  • 3กด Download — ไฟล์เซฟลงเครื่อง
  • 📤หรือคัดลอกลิงก์ส่งครูทาง Classroom
💡 งานใน Canva เซฟอัตโนมัติบนเว็บ ไม่หาย แต่ต้อง Download ก่อนส่งครู
👩‍🏫 สอนให้เล่าข้อมูลเป็นเรื่อง ไม่ใช่อ่านตัวเลขเฉยๆ

🎤 นำเสนอข้อมูลให้น่าฟัง

เล่าเป็นเรื่อง

• เริ่มจากคำถามที่สำรวจ

• ชี้กราฟแล้วบอกสิ่งที่เห็น

• สรุปว่าข้อมูลบอกอะไร

ท่าทาง

• ยืนหันหน้าหาผู้ฟัง

• พูดชัด มั่นใจ ไม่อ่านสไลด์

• สบตาผู้ฟัง

👩‍🏫 แจกข้อมูลให้นักเรียนแต่ละคน หรือให้สำรวจข้อมูลเอง
📊

งาน: Infographic ของฉัน (Canva)

📋 โจทย์

หัวข้อ: "สำรวจความชอบในชั้นเรียน"
• สำรวจ: อาหาร / วิชา / กีฬา / ของขวัญ ที่ชอบที่สุด
• เลือกกราฟ 1 แบบ ที่เหมาะกับข้อมูล (Bar/Pie/Line)
• ทำ Infographic 1 หน้า ใน Canva ให้สวย: กราฟ + ไอคอน + 3 สี

👩‍🏫 แจกเกณฑ์การให้คะแนน ให้นักเรียนอ่านก่อนส่งงาน

📋 เกณฑ์การให้คะแนน (20 คะแนน)

เนื้อหา (10 คะแนน)

• ข้อมูลถูกต้องครบถ้วน (4)

• กราฟตรงกับประเภทข้อมูล (3)

• สรุปข้อมูลถูกต้อง (3)

การนำเสนอ (10 คะแนน)

• ออกแบบสวยงาม (4)

• นำเสนอชัดเจนมั่นใจ (3)

• ตอบคำถามได้ (3)

👩‍🏫 ย้ำเรื่องความซื่อสัตย์ของข้อมูลและการอ้างอิงแหล่งที่มา

⚖️ นำเสนอข้อมูลอย่างซื่อสัตย์

  • ✅ใช้ข้อมูลจริง ไม่ปั้นตัวเลขขึ้นเอง
  • 📏กราฟต้องเริ่มจาก 0 ไม่บิดเบือนสัดส่วน
  • 🔖ระบุ แหล่งที่มา ของข้อมูลเสมอ
  • 🖼️ใช้รูป/ไอคอนที่มีสิทธิ์ใช้งานได้
👩‍🏫 สรุปบทเรียน ให้นักเรียน 2-3 คนนำเสนองาน
สรุปบทเรียน หน่วยที่ 2

🎓 สรุป: นำเสนอข้อมูลด้วยภาพ

  • 📊Data Visualization = ทำข้อมูลให้เป็นภาพ เข้าใจง่าย
  • 📊Bar = เปรียบเทียบ | Pie = สัดส่วน | Line = แนวโน้ม
  • 🖼️Infographic = กราฟ + รูป + ข้อความ สวยงาม
  • ⚖️นำเสนอข้อมูลอย่างซื่อสัตย์ + อ้างอิงแหล่งที่มา
