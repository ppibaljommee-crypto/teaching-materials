👩‍🏫 ให้นักเรียน 6 คนยืนถือป้ายตัวเลข แล้วทำ Bubble Sort จริงๆ — สนุกและจำได้นาน

🫧 Bubble Sort — เปรียบและสลับ

วิธีการ Bubble Sort:

1. เริ่มที่คู่แรก → ถ้าตัวซ้าย > ตัวขวา → สลับที่
2. เลื่อนไปคู่ถัดไป → ทำซ้ำจนถึงคู่สุดท้าย
3. วนรอบใหม่ → ทำซ้ำจนไม่มีการสลับอีก

👩‍🏫 เปรียบ Selection Sort กับการหยิบของราคาถูกที่สุดมาก่อน — ให้นักเรียนช่วยทำ Selection Sort กับตัวเลข [4, 2, 7, 1] บนกระดาน

🎯 Selection Sort — เลือกค่าน้อยสุด

วิธีการ Selection Sort:

1. หาค่าน้อยที่สุดในทั้งหมด → เอาไปไว้อันดับแรก
2. หาค่าน้อยที่สุดในส่วนที่เหลือ → เอาไปอันดับสอง
3. ทำซ้ำจนเรียงครบทุกตัว

Bubble Sort

• เปรียบทีละคู่

• สลับถ้าผิดที่

• วนหลายรอบ

Selection Sort

• หาค่าน้อยสุด

• เอาไปวางตำแหน่งที่ถูก

• สลับน้อยกว่า Bubble

💻 Pseudocode ของ Bubble Sort

// Bubble Sort — เรียงจากน้อยไปมาก START INPUT รายการตัวเลข arr[] SET n = จำนวนสมาชิกใน arr FOR i = 0 TO n-1 FOR j = 0 TO n-i-2 IF arr[j] > arr[j+1] THEN SWAP(arr[j], arr[j+1]) // สลับที่ ENDIF ENDFOR ENDFOR OUTPUT arr[] // แสดงผลที่เรียงแล้ว END
👩‍🏫 ให้นักเรียนอ่าน Pseudocode และตอบคำถาม ฝึกทักษะการ "อ่านโค้ด" ก่อน "เขียนโค้ด"

🔍 อ่าน Pseudocode: แต่ละบรรทัดหมายความว่าอะไร?

บรรทัดสำคัญ

FOR i = 0 TO n-1

✅ วนซ้ำ n รอบ (เท่ากับจำนวนสมาชิก) เพื่อเรียงให้ครบ

บรรทัดสำคัญ

IF arr[j] > arr[j+1] THEN SWAP

✅ ถ้าตัวซ้ายมากกว่าตัวขวา ให้สลับตำแหน่ง

คำถาม: FOR ซ้อน FOR ทำไม?

✅ FOR วงนอก = วนกี่รอบ | FOR วงใน = เปรียบทีละคู่ในแต่ละรอบ

คำถาม: n-i-2 คืออะไร?

✅ ตัวท้ายสุดที่เรียงครบแล้วไม่ต้องเปรียบอีก ทำให้เร็วขึ้น
👩‍🏫 ให้นักเรียน trace [3, 1, 2] ทีละขั้น บนกระดาน — กี่รอบถึงจะเรียงครบ?

🔍 Trace: เรียง [3, 1, 2] ด้วย Bubble Sort

รอบที่ 1: [3, 1, 2] → 3>1? สลับ → [1, 3, 2] → 3>2? สลับ → [1, 2, 3]

รอบที่ 2: [1, 2, 3] → ไม่มีสลับ → เสร็จ! ✅

✅ 2 รอบ — เพราะรอบที่ 2 ไม่มีการสลับแล้ว แสดงว่าเรียงครบ
👩‍🏫 ให้นักเรียนทำใน สมุด — trace เองทีละขั้น ไม่คุยกับเพื่อน เสร็จแล้วเปรียบกัน
