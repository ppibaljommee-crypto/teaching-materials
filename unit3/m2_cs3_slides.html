def — Function คืออะไร?

Function = ชุดคำสั่งที่ตั้งชื่อได้

• เขียนครั้งเดียว เรียกใช้ได้บ่อยครั้ง

• ลดการเขียนโค้ดซ้ำ

• ทำให้โค้ดอ่านง่ายขึ้น

• แก้ไขที่เดียว ทำงานทั้งโปรแกรม

    # คำสั่งภายใน

return — ส่งค่ากลับ

print vs return

👩‍🏫 เปรียบ List กับ "รายการสิ่งของ" — กล่องหลายช่องในกล่องเดียว, index เริ่มที่ 0

list — รายการข้อมูล

List คืออะไร?

• เก็บข้อมูลหลายค่าในตัวแปรเดียว

• เข้าถึงด้วย index (เริ่มจาก 0)

• แก้ไข เพิ่ม ลบได้

scores = [80, 75, 90]
scores[0] → 80 (ตัวแรก)
scores[-1] → 90 (ตัวสุดท้าย)
len(scores) → 3

⚠️ Index เริ่มที่ 0 เสมอ!

👩‍🏫 Slicing = "ตัดแบ่ง" List — เน้น [start:end] ไม่รวม end

List Slicing — [start:end]

ตัดส่วนของ List

nums = [10,20,30,40,50]
nums[1:3] → [20,30] # ไม่รวม 3
nums[:2] → [10,20] # ตั้งแต่ต้น
nums[3:] → [40,50] # ถึงท้าย
nums[-2:] → [40,50] # 2 ตัวท้าย
nums[::2] → [10,30,50] # เว้น 1

⚠️ [start:end] ได้ตั้งแต่ start ถึง end-1

# ระบบเก็บและวิเคราะห์คะแนน def get_grade(score): if score >= 80: return "A" elif score >= 70: return "B" elif score >= 60: return "C" else: return "F" def analyze(scores): avg = sum(scores) / len(scores) print(f"เฉลี่ย: {avg:.1f}") print(f"สูงสุด: {max(scores)}") print(f"ต่ำสุด: {min(scores)}") return avg scores = [85, 72, 90, 68, 78] for s in scores: print(f"{s} → เกรด {get_grade(s)}") avg = analyze(scores) print(f"เกรดเฉลี่ย: {get_grade(avg)}")

nums = [1, 2, 3]
result = []
for n in nums:

print(result)
