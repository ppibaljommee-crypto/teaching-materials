File • Folder • File Explorer • จัดระเบียบข้อมูล

👩‍🏫 เปรียบไฟล์เป็นกระดาษแผ่นหนึ่ง โฟลเดอร์เป็นแฟ้มที่เก็บกระดาษหลายแผ่น

📄 ไฟล์ (File) คืออะไร?

ไฟล์ = ชิ้นข้อมูล ที่เก็บอยู่ในคอมพิวเตอร์
เหมือนกระดาษแต่ละแผ่น ที่มีข้อมูลอยู่ข้างใน

ชนิดของไฟล์

📝 ไฟล์ข้อความ (.txt, .doc)

🖼️ ไฟล์รูปภาพ (.jpg, .png)

🎵 ไฟล์เสียง (.mp3)

🎬 ไฟล์วิดีโอ (.mp4)

ชื่อไฟล์

ทุกไฟล์มี ชื่อ และ นามสกุล

เช่น: รูปแมว.jpg

ชื่อ = รูปแมว

นามสกุล = .jpg (บอกชนิด)

👩‍🏫 แสดงภาพโฟลเดอร์สีเหลืองบนหน้าจอ ถามว่า "ในชั้นเรียนมีอะไรที่คล้ายโฟลเดอร์บ้าง?"

📂 โฟลเดอร์ (Folder) คืออะไร?

โฟลเดอร์ = กล่องเก็บไฟล์ หลายไฟล์
เหมือนแฟ้มเอกสาร หรือกล่องใส่ของ

📂 เอกสารของฉัน
  📂 การบ้าน
    📄 การบ้านคณิต.docx
    📄 การบ้านวิทย์.docx
  📂 รูปภาพ
    🖼️ ครอบครัว.jpg
    🖼️ โรงเรียน.jpg

โฟลเดอร์ในโฟลเดอร์ เรียกว่า Sub-folder

👩‍🏫 เปรียบกับโต๊ะเรียนรก — หาของไม่เจอ เสียเวลา คอมพิวเตอร์ก็เหมือนกัน

🤔 ทำไมต้องจัดไฟล์ให้เป็นระเบียบ?

😵 ถ้าไม่จัดระเบียบ

• หาไฟล์ไม่เจอ เสียเวลา

• ไฟล์ปนกันมั่ว

• เผลอลบไฟล์สำคัญ

• ไฟล์ชื่อซ้ำ สับสน

😊 ถ้าจัดระเบียบดี

• หาไฟล์เจอเร็ว

• รู้ว่าไฟล์อะไรอยู่ที่ไหน

• ทำงานเป็นระบบ

• ไม่เผลอลบของสำคัญ

โต๊ะเรียนเป็นระเบียบ = หาของง่าย 📚 คอมพิวเตอร์ก็เหมือนกัน!

👩‍🏫 เปิด File Explorer บนคอมพิวเตอร์ แนะนำแต่ละส่วน ชี้ที่ Address Bar, Navigation Pane

🗂️ File Explorer คืออะไร?

  • 1File Explorer = โปรแกรมดูและจัดการไฟล์/โฟลเดอร์
  • 2เปิดได้โดย: กด 🪟 Windows + E หรือกด This PC บน Desktop
  • 3Navigation Pane (ซ้าย) = แสดงโครงสร้างโฟลเดอร์
  • 4Main Area (กลาง) = แสดงไฟล์ในโฟลเดอร์ที่เลือก
  • 5Address Bar (บน) = แสดงตำแหน่งปัจจุบัน
👩‍🏫 สาธิตสร้างโฟลเดอร์ใหม่ทีละขั้น ให้นักเรียนทำตาม

📁 สร้างโฟลเดอร์ใหม่

  • 1เปิด File Explorer ไปยังที่ต้องการสร้าง
  • 2คลิกขวา ที่พื้นที่ว่าง → เลือก "New" → "Folder"
  • 3หรือ กดปุ่ม New Folder บน Toolbar ด้านบน
  • 4พิมพ์ชื่อโฟลเดอร์ ที่ต้องการ
  • 5กด Enter เพื่อยืนยัน
👩‍🏫 สาธิตการย้าย (Cut+Paste) คัดลอก (Copy+Paste) และลบไฟล์ ให้นักเรียนทำตาม

✂️ ย้าย • 📋 คัดลอก • 🗑️ ลบไฟล์

✂️ ย้ายไฟล์

1. คลิกเลือกไฟล์

2. กด Ctrl + X (Cut)

3. ไปที่โฟลเดอร์ปลายทาง

4. กด Ctrl + V (Paste)

ไฟล์หายจากที่เดิม

📋 คัดลอกไฟล์

1. คลิกเลือกไฟล์

2. กด Ctrl + C (Copy)

3. ไปที่โฟลเดอร์ปลายทาง

4. กด Ctrl + V (Paste)

ไฟล์ยังอยู่ที่เดิมด้วย

🗑️ ลบไฟล์

1. คลิกเลือกไฟล์

2. กด Delete

3. ไฟล์ไปอยู่ที่ Recycle Bin

ยังกู้คืนได้จาก Recycle Bin

🔄 เปลี่ยนชื่อ

1. คลิกขวาที่ไฟล์

2. เลือก Rename

3. พิมพ์ชื่อใหม่

4. กด Enter

👩‍🏫 สาธิตเลือกหลายไฟล์ด้วย Ctrl และ Shift ให้นักเรียนลองทำ

🖱️ เลือกหลายไฟล์พร้อมกัน

เลือกทีละไฟล์ (กระจาย)

กด Ctrl ค้างไว้

แล้วคลิกไฟล์ที่ต้องการทีละไฟล์

เลือกเฉพาะไฟล์ที่คลิก

เลือกเป็นช่วง (ติดกัน)

คลิกไฟล์แรก

กด Shift ค้าง แล้วคลิกไฟล์สุดท้าย

เลือกทุกไฟล์ระหว่างนั้น

เลือกหลายไฟล์ = ย้าย/คัดลอก/ลบ ได้ทีเดียวหลายไฟล์ ⚡
กด Ctrl + A = เลือกทั้งหมดในโฟลเดอร์

👩‍🏫 เน้นการตั้งชื่อไฟล์ที่ดี ช่วยให้หาไฟล์ได้เร็วในอนาคต

✏️ ตั้งชื่อไฟล์และโฟลเดอร์ที่ดี

❌ ชื่อที่ไม่ดี

• untitled.docx

• aaaa.jpg

• การบ้าน (ไม่รู้วิชาอะไร)

• file1, file2, file3...

• New Folder (1), (2)...

✅ ชื่อที่ดี

• การบ้านคณิต_ป1_2568.docx

• รูปครอบครัว_วันปีใหม่.jpg

• งาน_วิทยาการ_หน่วย3.docx

• รายงาน_เรื่องสัตว์.docx

ชื่อที่ดี: บอกเนื้อหา + วิชา/วันที่ — ค้นหาง่ายแม้ผ่านไปนาน

👩‍🏫 ให้นักเรียนดูไอคอนไฟล์ต่างๆ บอกว่าไอคอนช่วยบอกชนิดไฟล์โดยไม่ต้องเปิด

🔖 นามสกุลไฟล์ & ไอคอนบอกชนิด

มองไอคอนก็รู้ว่าเป็นไฟล์อะไร โดยไม่ต้องเปิด

📝 ไฟล์เอกสาร

📄 .docx → Word (เอกสาร)

📊 .xlsx → Excel (ตาราง)

📑 .pdf → เอกสาร PDF

📃 .txt → ข้อความธรรมดา

🎨 ไฟล์สื่อ

🖼️ .jpg .png → รูปภาพ

🎵 .mp3 → เสียง/เพลง

🎬 .mp4 → วิดีโอ

🗜️ .zip → ไฟล์บีบอัด

⚠️ อย่าเปลี่ยนนามสกุลไฟล์เอง อาจทำให้เปิดไม่ได้!

👩‍🏫 สาธิตช่อง Search ใน File Explorer — พิมพ์ชื่อไฟล์แล้วเจอเร็ว

🔍 ค้นหาไฟล์ที่หาไม่เจอ

ถ้าจำไม่ได้ว่าไฟล์อยู่ไหน → ใช้ ช่องค้นหา (Search)

  • 1เปิด File Explorer มองมุมขวาบน จะมีช่อง 🔍 Search
  • 2พิมพ์ชื่อไฟล์ (หรือบางส่วนของชื่อ)
  • 3คอมพิวเตอร์จะแสดงไฟล์ที่ตรงกันทันที

นี่คือเหตุผลที่ ตั้งชื่อไฟล์ให้ดี สำคัญมาก — ค้นหาเจอง่าย!

👩‍🏫 เน้นว่าการลบไฟล์ธรรมดาไปอยู่ที่ Recycle Bin ยังกู้คืนได้ แต่ถ้า Empty ไปแล้วหายถาวร

🗑️ Recycle Bin — ถังขยะคอมพิวเตอร์

Recycle Bin = ถังขยะชั่วคราว
ไฟล์ที่ลบจะอยู่ที่นี่ก่อน ยังกู้คืนได้!

  • 1กู้คืนไฟล์ — เปิด Recycle Bin → คลิกขวาไฟล์ → Restore
  • 2ลบถาวร — คลิกขวา → Delete หรือ Empty Recycle Bin
  • 3ระวัง! — หลัง Empty แล้วกู้คืนไม่ได้อีก
👩‍🏫 ย้ำ Ctrl+S บ่อยๆ กันงานหาย — แยก Save กับ Save As ให้ชัด

⚠️ ข้อควรระวังในการจัดการไฟล์

  • 1🗑️ อย่าลบไฟล์ที่ไม่รู้จัก — อาจเป็นไฟล์ของระบบ
