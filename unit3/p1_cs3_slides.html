👩‍🏫 ยกตัวอย่างจริง: ดินสอหาย ใช้ 4 ขั้นตอน

✏️ ตัวอย่าง: ดินสอหาย!

  • 1🔍 ระบุปัญหา: ดินสอไม่อยู่บนโต๊ะ
  • 2📋 วางแผน: หาในกระเป๋า → ถามเพื่อน → ยืมครู
  • 3🛠️ ลงมือทำ: เปิดกระเป๋า → ค้นหา → เจอแล้ว!
  • 4✅ ตรวจสอบ: ดินสอเขียนได้ไหม? ถ้าได้ = แก้ได้!
👩‍🏫 ตัวอย่างที่ 2 ใช้ 4 ขั้นตอนเดิม — ย้ำว่าใช้ได้กับทุกปัญหา

🧱 ตัวอย่าง: ต่อบล็อกแล้วล้ม!

  • 1🔍 ระบุปัญหา: ต่อบล็อกสูงแล้วล้มทุกครั้ง
  • 2📋 วางแผน: ฐานกว้างขึ้น · ต่อช้าๆ · วางให้ตรง
  • 3🛠️ ลงมือทำ: เริ่มจากฐานใหญ่ แล้วค่อยต่อขึ้น
  • 4✅ ตรวจสอบ: ตั้งอยู่ไม่ล้ม = แก้ได้!

4 ขั้นตอนเดิม ใช้ได้กับทุกปัญหา 💪

👩‍🏫 กิจกรรมกลุ่ม: แจกการ์ดปัญหา ให้แต่ละกลุ่มคิด 4 ขั้นตอน

🎮 กิจกรรม: แก้ปัญหาเป็นทีม

📋 โจทย์สถานการณ์

🎒 กลุ่ม A: ลืมทำการบ้าน
🖨️ กลุ่ม B: เครื่องพิมพ์ไม่ทำงาน
🔋 กลุ่ม C: แท็บเล็ตแบตหมด
🌐 กลุ่ม D: เน็ตหลุด
👩‍🏫 ถามว่า Debug คืออะไร — เชื่อมกับ หน่วย 1 ลองผิดลองถูก

🐛 Debug คือการแก้ข้อผิดพลาด

Debug = ค้นหาและแก้ไขข้อผิดพลาด
ใช้ได้กับโปรแกรม ชีวิต และงาน

ขั้นตอน Debug

1. พบว่ามีอะไรผิดพลาด

2. หาว่าผิดที่ตรงไหน

3. แก้ไขจุดนั้น

4. ทดสอบอีกครั้ง

🐞 ตัวอย่าง Bug ในชีวิต

• ทำสูตรผิด → ผลลัพธ์ผิด

• ลืมใส่เกลือ → อาหารไม่อร่อย

• พิมพ์ผิด → ส่งอีเมลผิดคน

👩‍🏫 เกมหาจุดผิด — ให้นักเรียนชี้ว่าผิดตรงไหน ฝึกสายตา Debug

🔎 เกม: หาจุดผิด (Bug)!

ลองหาว่าแต่ละอันผิดตรงไหน แล้วบอกวิธีแก้

  • 🐛นับเลข: 1 · 2 · 3 · 5 · 4 · 6 → ผิดตรงไหน?
  • 🐛ABC: A · B · D · C · E → ตัวไหนสลับที่?
  • 🐛ระบายสีไฟจราจร: 🔴 🟡 🔵 → สีไหนผิด?
เลข 5 สลับกับ 4 · ตัว D ควรเป็น C · สีฟ้าควรเป็นสีเขียว 🟢

  • 2😮‍💨 พักสักครู่ — พักแล้วกลับมาคิดใหม่

👩‍🏫 กิจกรรมเขาวงกต: ให้นักเรียนวางแผนก่อนลงมือ ไม่ใช่ลองไปเรื่อยๆ
