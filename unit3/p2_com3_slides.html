สร้างโปสเตอร์
สัตว์โปรดด้วย Paint!

Microsoft Paint • วาดรูป • ตกแต่ง • บันทึก

👩‍🏫 เปิด Paint บนคอมพิวเตอร์ แนะนำว่าเป็นโปรแกรมวาดรูปที่ติดมากับ Windows ฟรี

🎨 Microsoft Paint คืออะไร?

Paint = โปรแกรม วาดและแต่งรูปภาพ
ติดมากับ Windows ทุกรุ่น ใช้งานง่าย ฟรี!

วิธีเปิด Paint

1. กด 🪟 Windows

2. พิมพ์ "Paint"

3. กด Enter

หรือค้นหาใน Search Bar

ทำอะไรได้?

🖌️ วาดรูปอิสระ

🔷 วาดรูปร่างต่างๆ

🎨 เลือกสีและเติมสี

✍️ พิมพ์ข้อความในรูป

💾 บันทึกเป็น .png, .jpg

👩‍🏫 ชี้แต่ละส่วนบน Paint จริงๆ ให้นักเรียนดูตาม ถามว่า "แต่ละส่วนทำอะไร?"

🖥️ ส่วนประกอบของ Paint

  • 1Ribbon (แถบเครื่องมือ) — แถบด้านบน มีทุกคำสั่ง
  • 2Canvas (พื้นที่วาด) — กระดาษดิจิตอลที่เราวาดรูป
  • 3Color Palette (แถบสี) — เลือกสีสำหรับวาดรูป
  • 4Tool Box (กล่องเครื่องมือ) — เครื่องมือวาดต่างๆ
  • 5Status Bar (แถบสถานะ) — แสดงขนาดและ zoom
👩‍🏫 สาธิตแต่ละเครื่องมือบน Paint ให้นักเรียนลองทดสอบทีละอย่าง

🛠️ เครื่องมือสำคัญใน Paint

เครื่องมือวาด

✏️ Pencil — ดินสอ วาดเส้นบาง

🖌️ Brush — แปรง เลือกขนาดได้

🪣 Fill — เทสีเต็มพื้นที่

🧹 Eraser — ยางลบ ลบสิ่งที่วาด

เครื่องมือรูปร่าง

📐 Line — วาดเส้นตรง

▭ Rectangle — สี่เหลี่ยม

⭕ Oval/Circle — วงรี/วงกลม

🔺 Triangle — สามเหลี่ยม

เครื่องมือสี

🎨 Color 1 — สีหลัก (คลิกซ้าย)

⬜ Color 2 — สีพื้นหลัง (คลิกขวา)

💉 Eyedropper — จิ้มดูดสีจากรูป

เครื่องมือข้อความ

✍️ Text (A) — พิมพ์ข้อความ

• เลือก Font (รูปแบบตัวอักษร)

• เลือก Size (ขนาด)

• Bold / Italic / Underline

👩‍🏫 สาธิตวาดแมวง่ายๆ ทีละขั้น ให้นักเรียนดูก่อนแล้วค่อยลองเอง

🐱 วิธีวาดสัตว์ง่ายๆ ทีละขั้น

  • 1วาด วงกลม = หัว | วงรี = ลำตัว
  • 2วาด สามเหลี่ยม 2 อัน = หูแมว
  • 3วาด วงกลมเล็กๆ = ตา 2 ข้าง + จมูก
  • 4วาด เส้นโค้ง = หาง / หนวด
  • 5ใช้ Fill เทสีที่ชอบ

ไม่ต้องสวยมาก! สำคัญคือ ความสนุก และ ความพยายาม

👩‍🏫 สาธิตการเพิ่มข้อความและตกแต่งใน Paint ให้นักเรียนดู

🌟 ตกแต่งโปสเตอร์

ข้อมูลในโปสเตอร์

📝 ชื่อสัตว์ (ภาษาไทย/อังกฤษ)

🏠 ที่อยู่อาศัย

🍖 อาหารที่กิน

❤️ ทำไมถึงชอบสัตว์นี้

เทคนิคตกแต่ง

• ใช้พื้นหลังสีสวยๆ

• ข้อความสีตัดกับพื้น

• วาดดอกไม้/ดาว รอบๆ

• ใส่กรอบรูปให้สวย

📝 ใช้ Text Tool พิมพ์ชื่อ 🎨 Fill สีพื้นหลัง 🖌️ Brush ตกแต่งขอบ ⭕ วงกลมตกแต่ง
👩‍🏫 เน้นการบันทึกให้บ่อย ไม่งั้นงานหาย สอนให้บันทึกทุก 5 นาที

💾 บันทึกงาน (Save)

  • 1กด Ctrl + S เพื่อ Save อย่างรวดเร็ว
  • 2หรือ กด File → Save As เพื่อตั้งชื่อใหม่
  • 3เลือก ชนิดไฟล์: PNG (คุณภาพสูง) หรือ JPEG
  • 4เลือก ที่บันทึก: โฟลเดอร์ที่ตั้งไว้
  • 5ตั้งชื่อให้ดี เช่น โปสเตอร์_แมว_ชื่อตัวเอง.png

⚠️ Save บ่อยๆ ทุก 5 นาที เผื่อไฟฟ้าดับหรือโปรแกรมค้าง!

👩‍🏫 ให้นักเรียนตอบ ไม่ต้องเร่ง

🎯 ทดสอบ: เครื่องมือใดใช้เทสีเต็มพื้นที่?

เลือกคำตอบที่ถูกต้อง

👩‍🏫 สาธิตเทคนิค Undo และการ Zoom ให้นักเรียนดู

⚡ เทคนิคที่ควรรู้

Shortcut ที่ใช้บ่อย

↩️ Ctrl + Z = Undo (ย้อนกลับ)

↪️ Ctrl + Y = Redo (ทำซ้ำ)

🔍 Ctrl + = = Zoom In

🔍 Ctrl + - = Zoom Out

💾 Ctrl + S = Save

เทคนิควาดรูป

• Shift + วาดรูปร่าง = วงกลม/สี่เหลี่ยมสมบูรณ์

• Zoom In เพื่อวาดรายละเอียดเล็กๆ

• วาดบน Layer ที่ต่างกัน (Paint 3D)

• ลองเลือก Fill Style ต่างๆ

👩‍🏫 แจกใบงานโปสเตอร์ ป.2 ให้นักเรียน เปิด Paint ให้เริ่มสร้างโปสเตอร์

กิจกรรม: สร้างโปสเตอร์สัตว์โปรด

📋 โจทย์

สร้างโปสเตอร์ สัตว์โปรด ของตัวเอง
ต้องมี: รูปสัตว์ + ชื่อสัตว์ + ข้อมูล 3 อย่าง + ตกแต่งสวยงาม

บันทึกชื่อ: โปสเตอร์_[ชื่อสัตว์]_[ชื่อตัวเอง].png

👩‍🏫 สรุปบทเรียน ให้นักเรียนนำเสนอโปสเตอร์ของตัวเองสั้นๆ
