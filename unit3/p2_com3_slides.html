สร้างโปสเตอร์
สัตว์โปรดด้วย Paint!

Microsoft Paint • วาดรูป • ตกแต่ง • บันทึก

👩‍🏫 เปิด Paint บนคอมพิวเตอร์ แนะนำว่าเป็นโปรแกรมวาดรูปที่ติดมากับ Windows ฟรี

🎨 Microsoft Paint คืออะไร?

Paint = โปรแกรม วาดและแต่งรูปภาพ
ติดมากับ Windows ทุกรุ่น ใช้งานง่าย ฟรี!

วิธีเปิด Paint

1. กด 🪟 Windows

2. พิมพ์ "Paint"

3. กด Enter

หรือค้นหาใน Search Bar

ทำอะไรได้?

🖌️ วาดรูปอิสระ

🔷 วาดรูปร่างต่างๆ

🎨 เลือกสีและเติมสี

✍️ พิมพ์ข้อความในรูป

💾 บันทึกเป็น .png, .jpg

👩‍🏫 ให้นักเรียนเปรียบเทียบ ข้อดีของการวาดด้วยคอมคืออะไร

🖌️ วาดด้วยคอม ต่างจากกระดาษอย่างไร?

✏️ วาดบนกระดาษ

• วาดผิดต้องลบ/เริ่มใหม่

• สีจำกัดตามที่มี

• ทำสำเนายาก

• ใช้กระดาษจริง

💻 วาดด้วย Paint

• ผิดกด Undo ย้อนได้ทันที

• สีเยอะมาก เลือกได้อิสระ

• คัดลอก/ส่งต่อง่าย

• บันทึกเก็บไว้ได้ตลอด

วาดด้วยคอม = แก้ไขง่าย ลองผิดลองถูกได้ไม่กลัวเสียกระดาษ 😊

👩‍🏫 ชี้แต่ละส่วนบน Paint จริงๆ ให้นักเรียนดูตาม ถามว่า "แต่ละส่วนทำอะไร?"

🖥️ ส่วนประกอบของ Paint

  • 1Ribbon (แถบเครื่องมือ) — แถบด้านบน มีทุกคำสั่ง
  • 2Canvas (พื้นที่วาด) — กระดาษดิจิตอลที่เราวาดรูป
  • 3Color Palette (แถบสี) — เลือกสีสำหรับวาดรูป
  • 4Tool Box (กล่องเครื่องมือ) — เครื่องมือวาดต่างๆ
  • 5Status Bar (แถบสถานะ) — แสดงขนาดและ zoom
👩‍🏫 สาธิตแต่ละเครื่องมือบน Paint ให้นักเรียนลองทดสอบทีละอย่าง

🛠️ เครื่องมือสำคัญใน Paint

เครื่องมือวาด

✏️ Pencil — ดินสอ วาดเส้นบาง

🖌️ Brush — แปรง เลือกขนาดได้

🪣 Fill — เทสีเต็มพื้นที่

🧹 Eraser — ยางลบ ลบสิ่งที่วาด

เครื่องมือรูปร่าง

📐 Line — วาดเส้นตรง

▭ Rectangle — สี่เหลี่ยม

⭕ Oval/Circle — วงรี/วงกลม

🔺 Triangle — สามเหลี่ยม

เครื่องมือสี

🎨 Color 1 — สีหลัก (คลิกซ้าย)

⬜ Color 2 — สีพื้นหลัง (คลิกขวา)

💉 Eyedropper — จิ้มดูดสีจากรูป

เครื่องมือข้อความ

✍️ Text (A) — พิมพ์ข้อความ

• เลือก Font (รูปแบบตัวอักษร)

• เลือก Size (ขนาด)

• Bold / Italic / Underline

👩‍🏫 สาธิต Edit Colors ผสมสีเอง — ให้นักเรียนลองสร้างสีที่ชอบ

🎨 เลือกสีและผสมสีเอง

เลือกสีสำเร็จรูป

• คลิกสีที่ Color Palette ด้านบน

• Color 1 = คลิกซ้ายวาด

• Color 2 = คลิกขวาวาด

ผสมสีเอง (Edit Colors)

• กดปุ่ม Edit Colors

• เลือกจากวงล้อสี

• ผสมได้สีใหม่นับล้านสี!

🌈 สีหลัก: แดง เหลือง น้ำเงิน · ผสมกันได้สีใหม่ เช่น แดง+เหลือง = ส้ม

👩‍🏫 สาธิต Select เลือกบางส่วน แล้วย้าย/ลบ/คัดลอก ให้นักเรียนดู

✂️ Select & Crop — เลือกและตัดภาพ

  • 1Select (เลือก) — ลากครอบส่วนของภาพที่ต้องการ
  • 2ส่วนที่เลือกแล้ว ย้าย • คัดลอก • ลบ ได้
  • 3Crop (ตัดขอบ) — เก็บเฉพาะส่วนที่เลือก ตัดที่เหลือทิ้ง
  • 4Resize — ปรับขนาดภาพให้ใหญ่/เล็กลง
  • 5Rotate — หมุนภาพ ซ้าย/ขวา/กลับด้าน
👩‍🏫 สาธิตวาดแมวง่ายๆ ทีละขั้น ให้นักเรียนดูก่อนแล้วค่อยลองเอง

🐱 วิธีวาดสัตว์ง่ายๆ ทีละขั้น

  • 1วาด วงกลม = หัว | วงรี = ลำตัว
  • 2วาด สามเหลี่ยม 2 อัน = หูแมว
  • 3วาด วงกลมเล็กๆ = ตา 2 ข้าง + จมูก
  • 4วาด เส้นโค้ง = หาง / หนวด
  • 5ใช้ Fill เทสีที่ชอบ

ไม่ต้องสวยมาก! สำคัญคือ ความสนุก และ ความพยายาม

👩‍🏫 เชื่อม "คิดก่อนทำ" — ร่างในกระดาษก่อนวาดจริงในคอม

📝 วางแผนโปสเตอร์ก่อนลงมือ

นักออกแบบเก่งๆ ร่างภาพคร่าวๆ ก่อนเสมอ

  • 1🐾 เลือกสัตว์: จะวาดสัตว์อะไร?
  • 2✏️ ร่างคร่าวๆ: วาดในกระดาษก่อนว่าจะวางอะไรตรงไหน
  • 3🎨 เลือกสีหลัก: โทนสีของโปสเตอร์
  • 4📄 วางข้อความ: ชื่อสัตว์อยู่ตรงไหน ข้อมูลอยู่ตรงไหน

วางแผนก่อน = วาดจริงเร็วขึ้น สวยขึ้น แก้น้อยลง ✨

👩‍🏫 สาธิตการเพิ่มข้อความและตกแต่งใน Paint ให้นักเรียนดู

🌟 ตกแต่งโปสเตอร์

ข้อมูลในโปสเตอร์

📝 ชื่อสัตว์ (ภาษาไทย/อังกฤษ)

🏠 ที่อยู่อาศัย

🍖 อาหารที่กิน

❤️ ทำไมถึงชอบสัตว์นี้

เทคนิคตกแต่ง

• ใช้พื้นหลังสีสวยๆ

• ข้อความสีตัดกับพื้น

• วาดดอกไม้/ดาว รอบๆ

• ใส่กรอบรูปให้สวย

📝 ใช้ Text Tool พิมพ์ชื่อ 🎨 Fill สีพื้นหลัง 🖌️ Brush ตกแต่งขอบ ⭕ วงกลมตกแต่ง
👩‍🏫 ยกตัวอย่างโปสเตอร์ดี vs รก ให้นักเรียนดูความต่าง

🌟 โปสเตอร์ที่ดีเป็นอย่างไร?

❌ โปสเตอร์ที่อ่านยาก

• ตัวอักษรเล็กเกินไป

• สีตัวอักษรกลืนพื้นหลัง

• ใส่ของเยอะจนรก

• วางมั่ว ไม่เป็นระเบียบ

✅ โปสเตอร์ที่ดี

• ตัวอักษรใหญ่ อ่านง่าย

• สีตัดกับพื้นหลังชัดเจน

• มีที่ว่างให้หายใจ ไม่รก

• รูปเด่นอยู่ตรงกลาง

หลักง่ายๆ: ใหญ่ ชัด อ่านง่าย มองแล้วเข้าใจทันที 👀

👩‍🏫 เน้นการบันทึกให้บ่อย ไม่งั้นงานหาย สอนให้บันทึกทุก 5 นาที

💾 บันทึกงาน (Save)

  • 1กด Ctrl + S เพื่อ Save อย่างรวดเร็ว
  • 2หรือ กด File → Save As เพื่อตั้งชื่อใหม่
  • 3เลือก ชนิดไฟล์: PNG (คุณภาพสูง) หรือ JPEG
  • 4เลือก ที่บันทึก: โฟลเดอร์ที่ตั้งไว้
  • 5ตั้งชื่อให้ดี เช่น โปสเตอร์_แมว_ชื่อตัวเอง.png

⚠️ Save บ่อยๆ ทุก 5 นาที เผื่อไฟฟ้าดับหรือโปรแกรมค้าง!

⚡ เทคนิคที่ควรรู้

Shortcut ที่ใช้บ่อย

↩️ Ctrl + Z = Undo (ย้อนกลับ)

↪️ Ctrl + Y = Redo (ทำซ้ำ)

🔍 Ctrl + = = Zoom In

🔍 Ctrl + - = Zoom Out

💾 Ctrl + S = Save

เทคนิควาดรูป

• Shift + วาดรูปร่าง = วงกลม/สี่เหลี่ยมสมบูรณ์

• Zoom In เพื่อวาดรายละเอียดเล็กๆ

• วาดบน Layer ที่ต่างกัน (Paint 3D)

• ลองเลือก Fill Style ต่างๆ

👩‍🏫 ปัญหาที่นักเรียนเจอบ่อยตอนใช้ Paint ให้รู้วิธีแก้ก่อนยกมือถาม

🔧 แก้ปัญหาที่พบบ่อยใน Paint

😣 ปัญหา

• เทสีแล้วเลอะทั้งจอ

• วาดเส้นหนา/บางเกินไป

• ลบไปโดนของที่ไม่อยากลบ

• พิมพ์ข้อความผิดที่

✅ วิธีแก้

• Fill รั่วเพราะเส้นไม่ปิด → ปิดเส้นก่อน

• ปรับ Size ของแปรง

• กด Ctrl+Z ย้อนทันที

• คลิกที่ใหม่ก่อนกด Text เสร็จ

เจอปัญหา = โอกาสฝึกแก้! กด Ctrl+Z แล้วลองใหม่ได้เสมอ 💪

กิจกรรม: สร้างโปสเตอร์สัตว์โปรด

📋 โจทย์

สร้างโปสเตอร์ สัตว์โปรด ของตัวเอง
ต้องมี: รูปสัตว์ + ชื่อสัตว์ + ข้อมูล 3 อย่าง + ตกแต่งสวยงาม

บันทึกชื่อ: โปสเตอร์_[ชื่อสัตว์]_[ชื่อตัวเอง].png

👩‍🏫 ให้นักเรียน 4-5 คนนำโปสเตอร์มาเล่า เปิดโอกาสให้เพื่อนชม

🎤 นำเสนอและชื่นชมผลงาน

🗣️ เล่าโปสเตอร์ของเรา

• สัตว์ที่วาดคืออะไร

• ทำไมถึงชอบสัตว์นี้

• ใช้เครื่องมืออะไรบ้าง

• ภูมิใจตรงไหนที่สุด

💖 ชมผลงานเพื่อน

• ตั้งใจฟังเพื่อนนำเสนอ

• ปรบมือให้กำลังใจ

• บอกสิ่งที่ชอบในงานเพื่อน

ทุกผลงานมีความตั้งใจ — ชื่นชมกันและกันนะครับ 🌟

👩‍🏫 สรุปบทเรียน ให้นักเรียนนำเสนอโปสเตอร์ของตัวเองสั้นๆ
