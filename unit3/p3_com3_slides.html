👩‍🏫 ชี้ Cell A1, B2, C3 บน Excel จริง ให้นักเรียนบอกชื่อ Cell ตาม

🗂️ Cell • Row • Column

🔲 Cell (ช่องข้อมูล)

ช่องสี่เหลี่ยมเล็กๆ ในตาราง

ชื่อ Cell = คอลัมน์ + แถว

เช่น A1 = คอลัมน์ A แถว 1

คลิกเซลล์แล้วพิมพ์ข้อมูล

↔️ Row & Column

📏 Row (แถว) = แนวนอน (1, 2, 3...)

📏 Column (คอลัมน์) = แนวตั้ง (A, B, C...)

ตัวอย่าง Cell:

A1, B3, C10, D25...

ลองคลิก Cell ต่างๆ — ดูที่ Name Box (มุมซ้ายบน) จะแสดงชื่อ Cell

👩‍🏫 อธิบายเครื่องหมาย : ว่าหมายถึง "ตั้งแต่...ถึง..." ให้นักเรียนอ่าน range ออก

📍 Cell Range — ช่วงของเซลล์

เครื่องหมาย : (โคลอน) = "ตั้งแต่...ถึง..."
ใช้บอกช่วงของเซลล์หลายช่อง

  • 1C2:C5 = เซลล์ C2 ถึง C5 (4 ช่องในคอลัมน์เดียว)
  • 2A1:A10 = A1 ถึง A10 (10 ช่องแนวตั้ง)
  • 3A1:C3 = สี่เหลี่ยมจาก A1 ถึง C3 (9 ช่อง)

อ่านว่า: =SUM(C2:C5) → "บวก C2 ถึง C5"

👩‍🏫 สาธิตการพิมพ์ข้อมูลลงตาราง ให้นักเรียนทำตามทีละขั้น

⌨️ พิมพ์ข้อมูลลงตาราง

วิธีพิมพ์ข้อมูล

1. คลิกเซลล์ที่ต้องการ

2. พิมพ์ข้อมูล

3. กด Enter = ไปแถวถัดไป

4. กด Tab = ไปคอลัมน์ถัดไป

ชนิดข้อมูล

📝 ข้อความ — ชื่อ รายการ

🔢 ตัวเลข — จำนวนเงิน

📅 วันที่ — วัน/เดือน/ปี

ตัวเลขชิดขวา ข้อความชิดซ้าย

ABCD
วันที่รายการรายรับรายจ่าย
1 มิ.ย.รับค่าขนม50
2 มิ.ย.ซื้อขนม20
👩‍🏫 สาธิตพิมพ์ =SUM(C2:C10) ให้นักเรียนเห็นว่าคำนวณได้เอง แล้วลองเปลี่ยนตัวเลข

➕ สูตร SUM — หาผลรวม

สูตร Excel ต้องเริ่มด้วย = เสมอ
Excel จะคำนวณให้อัตโนมัติ!

=SUM(C2:C10)
// บวกตัวเลขในช่อง C2 ถึง C10 ทั้งหมด

=SUM(C2,C5,C8)
// บวกเฉพาะ C2, C5, C8

ลองพิมพ์ =SUM( แล้วลากเลือกช่วงเซลล์ แล้วกด Enter

👩‍🏫 สาธิตแต่ละสูตร ให้นักเรียนลองพิมพ์บน Excel จริง

📐 สูตร AVERAGE • MAX • MIN

=AVERAGE()

=AVERAGE(C2:C10)

หาค่าเฉลี่ย (ค่าเฉลี่ย = ผลรวม ÷ จำนวน)

เช่น ค่าใช้จ่ายเฉลี่ยต่อวัน

=MAX() และ =MIN()

=MAX(C2:C10)
=MIN(C2:C10)

MAX = หาค่ามากที่สุด
MIN = หาค่าน้อยที่สุด

สูตรทั้งหมดใช้ได้กับช่วงตัวเลขใดก็ได้ แค่เปลี่ยน C2:C10 ให้ตรงกับตาราง

👩‍🏫 สาธิตลากมุมเซลล์เพื่อก็อปปี้สูตร/ลำดับ — ประหยัดเวลามาก

🪄 Auto Fill — คัดลอกอัตโนมัติ

ลากมุมขวาล่างของเซลล์ (Fill Handle)
Excel จะเติมข้อมูลต่อให้อัตโนมัติ

เติมลำดับ

พิมพ์ 1, 2 → ลาก → 3,4,5...

พิมพ์ จันทร์ → ลาก → อังคาร, พุธ...

พิมพ์ ม.ค. → ลาก → ก.พ., มี.ค...

คัดลอกสูตร

เขียน =C2+D2 ที่แถวแรก

ลากลงมา → Excel ปรับเป็น

=C3+D3, =C4+D4... ให้เอง!

👩‍🏫 COUNT นับจำนวนช่องที่มีตัวเลข — ใช้นับจำนวนรายการ

🔢 สูตร COUNT — นับจำนวน

=COUNT()

=COUNT(C2:C10)

นับว่ามีกี่ช่องที่มีตัวเลข

เช่น นับว่ามีรายการกี่รายการ

ใช้คู่กับสูตรอื่น

• SUM = ผลรวมทั้งหมด

• COUNT = จำนวนรายการ

• SUM ÷ COUNT = ค่าเฉลี่ย

(เหมือนกับ AVERAGE!)

กิจกรรม: สร้างบัญชีรายรับรายจ่าย

📋 โจทย์

สร้างตาราง รายรับรายจ่ายประจำสัปดาห์
บันทึก 7 วัน + หาผลรวม รายรับ-รายจ่าย + คงเหลือ

ใช้สูตร: SUM, AVERAGE, MAX, MIN อย่างน้อย 2 สูตร

👩‍🏫 เชื่อมโยงสู่การออม — จดรายรับรายจ่ายช่วยให้รู้ว่าเงินไปไหน ออมได้

💡 ทำบัญชีช่วยเรื่องการออม

📒 ประโยชน์ของการจดบัญชี

• รู้ว่าเงินไปไหนหมด

• เห็นว่าใช้จ่ายอะไรมากเกินไป

• วางแผนการออมได้

• ตั้งเป้าหมายเก็บเงินซื้อของที่อยากได้

🐷 เคล็ดลับการออม

• แบ่งเงินออมก่อนใช้

• จดทุกครั้งที่ใช้เงิน

• ตั้งเป้าออมต่อสัปดาห์

🎓 สรุป: บัญชีรายรับรายจ่ายด้วย Excel

  • 📊Excel = โปรแกรมตารางคำนวณ จัดข้อมูลเป็นตาราง
