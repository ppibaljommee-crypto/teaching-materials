Microsoft Excel • Cell • สูตร SUM/AVERAGE/MAX/MIN

👩‍🏫 เปิด Excel บนคอมพิวเตอร์ แสดงว่า Excel คือตารางขนาดใหญ่ที่คำนวณได้

📊 Microsoft Excel คืออะไร?

Excel = โปรแกรม ตารางคำนวณ (Spreadsheet)
จัดเก็บข้อมูลเป็นตาราง + คำนวณสูตรอัตโนมัติ

ใช้ Excel ทำอะไร?

• จดรายรับรายจ่าย

• คำนวณค่าต่างๆ อัตโนมัติ

• สร้างกราฟแสดงข้อมูล

• จัดเก็บข้อมูลเป็นตาราง

ใครใช้ Excel?

🏪 นักธุรกิจ — บัญชีร้านค้า

👨‍🏫 ครู — บันทึกคะแนน

🏥 พยาบาล — ข้อมูลผู้ป่วย

👨‍👩‍👧‍👦 ครอบครัว — งบประมาณ

👩‍🏫 ชี้ Cell A1, B2, C3 บน Excel จริง ให้นักเรียนบอกชื่อ Cell ตาม

🗂️ Cell • Row • Column

🔲 Cell (ช่องข้อมูล)

ช่องสี่เหลี่ยมเล็กๆ ในตาราง

ชื่อ Cell = คอลัมน์ + แถว

เช่น A1 = คอลัมน์ A แถว 1

คลิกเซลล์แล้วพิมพ์ข้อมูล

↔️ Row & Column

📏 Row (แถว) = แนวนอน (1, 2, 3...)

📏 Column (คอลัมน์) = แนวตั้ง (A, B, C...)

ตัวอย่าง Cell:

A1, B3, C10, D25...

ลองคลิก Cell ต่างๆ — ดูที่ Name Box (มุมซ้ายบน) จะแสดงชื่อ Cell

👩‍🏫 สาธิตการพิมพ์ข้อมูลลงตาราง ให้นักเรียนทำตามทีละขั้น

⌨️ พิมพ์ข้อมูลลงตาราง

วิธีพิมพ์ข้อมูล

1. คลิกเซลล์ที่ต้องการ

2. พิมพ์ข้อมูล

3. กด Enter = ไปแถวถัดไป

4. กด Tab = ไปคอลัมน์ถัดไป

ชนิดข้อมูล

📝 ข้อความ — ชื่อ รายการ

🔢 ตัวเลข — จำนวนเงิน

📅 วันที่ — วัน/เดือน/ปี

ตัวเลขชิดขวา ข้อความชิดซ้าย

ABCD
วันที่รายการรายรับรายจ่าย
1 มิ.ย.รับค่าขนม50
2 มิ.ย.ซื้อขนม20
👩‍🏫 สาธิตพิมพ์ =SUM(C2:C10) ให้นักเรียนเห็นว่าคำนวณได้เอง แล้วลองเปลี่ยนตัวเลข

➕ สูตร SUM — หาผลรวม

สูตร Excel ต้องเริ่มด้วย = เสมอ
Excel จะคำนวณให้อัตโนมัติ!

=SUM(C2:C10)
// บวกตัวเลขในช่อง C2 ถึง C10 ทั้งหมด

=SUM(C2,C5,C8)
// บวกเฉพาะ C2, C5, C8

ลองพิมพ์ =SUM( แล้วลากเลือกช่วงเซลล์ แล้วกด Enter

👩‍🏫 สาธิตแต่ละสูตร ให้นักเรียนลองพิมพ์บน Excel จริง

📐 สูตร AVERAGE • MAX • MIN

=AVERAGE()

=AVERAGE(C2:C10)

หาค่าเฉลี่ย (ค่าเฉลี่ย = ผลรวม ÷ จำนวน)

เช่น ค่าใช้จ่ายเฉลี่ยต่อวัน

=MAX() และ =MIN()

=MAX(C2:C10)
=MIN(C2:C10)

MAX = หาค่ามากที่สุด
MIN = หาค่าน้อยที่สุด

สูตรทั้งหมดใช้ได้กับช่วงตัวเลขใดก็ได้ แค่เปลี่ยน C2:C10 ให้ตรงกับตาราง

👩‍🏫 สาธิตสร้างตารางรายรับรายจ่ายทั้งหมด ให้นักเรียนสร้างตาม

💰 ตารางรายรับรายจ่ายสมบูรณ์

A: วันที่B: รายการC: รายรับ (บาท)D: รายจ่าย (บาท)
1 มิ.ย.รับค่าขนม50
2 มิ.ย.ซื้อขนม20
3 มิ.ย.รับเงินพิเศษ30
4 มิ.ย.ซื้อดินสอ15
รวมทั้งหมด=SUM(C2:C5)=SUM(D2:D5)
คงเหลือ=C6-D6
👩‍🏫 ให้นักเรียนคิดก่อนตอบ ไม่ต้องเปิดดูสไลด์

🎯 ทดสอบ: สูตรอะไรใช้หาผลรวม?

เลือกคำตอบที่ถูกต้อง

👩‍🏫 สาธิตการจัดรูปแบบ ทำให้ตารางสวยและอ่านง่ายขึ้น

🎨 จัดรูปแบบตารางให้สวย

จัดรูปแบบพื้นฐาน

• Bold หัวตาราง (Ctrl+B)

• เปลี่ยน สีพื้นหลัง Cell

• ขีดเส้นกรอบ ตาราง

• กว้างคอลัมน์ (ดับเบิลคลิกขอบ)

จัดรูปแบบตัวเลข

• เปลี่ยนเป็น รูปแบบเงินบาท

• ใส่ จุดทศนิยม กี่ตำแหน่ง

• จัดตาราง ชิดกลาง/ซ้าย/ขวา

กิจกรรม: สร้างบัญชีรายรับรายจ่าย

📋 โจทย์

สร้างตาราง รายรับรายจ่ายประจำสัปดาห์
บันทึก 7 วัน + หาผลรวม รายรับ-รายจ่าย + คงเหลือ

ใช้สูตร: SUM, AVERAGE, MAX, MIN อย่างน้อย 2 สูตร

👩‍🏫 สรุปบทเรียน ถามนักเรียนว่าสูตร SUM แตกต่างจาก AVERAGE อย่างไร

🎓 สรุป: บัญชีรายรับรายจ่ายด้วย Excel

  • 📊Excel = โปรแกรมตารางคำนวณ จัดข้อมูลเป็นตาราง
  • 🔲Cell = ช่องข้อมูล ชื่อ = คอลัมน์+แถว (A1, B2...)
  • ➕=SUM() = ผลรวม | =AVERAGE() = ค่าเฉลี่ย
  • 📈=MAX() = ค่าสูงสุด | =MIN() = ค่าต่ำสุด
  • 💰ตารางรายรับรายจ่าย = คำนวณคงเหลือได้อัตโนมัติ
