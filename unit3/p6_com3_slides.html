จัดการข้อมูล
อย่างมีระบบ

Sort • Filter • PivotTable • VLOOKUP

👩‍🏫 ยกตัวอย่างชีวิตจริง: "ห้องสมุดจัดหนังสือเป็นหมวด ถ้าไม่จัด หาหนังสือได้ยังไง?"

🤔 ทำไมต้องจัดการข้อมูล?

ปัญหาเมื่อไม่จัด

❌ หาข้อมูลไม่เจอ

❌ ใช้เวลานานในการค้นหา

❌ วิเคราะห์ข้อมูลไม่ได้

❌ ตัดสินใจผิดพลาด

ประโยชน์เมื่อจัดข้อมูลดี

✅ ค้นหาข้อมูลได้รวดเร็ว

✅ วิเคราะห์แนวโน้มได้

✅ ตัดสินใจได้ดีขึ้น

✅ ประหยัดเวลา

วันนี้เรียน 4 เครื่องมือ: Sort → Filter → PivotTable → VLOOKUP

👩‍🏫 แยกข้อมูลดิบ (ตัวเลขดิบ) กับสารสนเทศ (ผ่านการประมวลผลแล้วมีความหมาย)

📦 ข้อมูล (Data) vs สารสนเทศ (Information)

📥 ข้อมูลดิบ (Data)

ตัวเลข/ข้อความที่ยังไม่ผ่านการคิด

เช่น: 85, 92, 78, 88, 90...

มองแล้วยังไม่รู้ว่าหมายถึงอะไร

📤 สารสนเทศ (Information)

ข้อมูลที่ประมวลผลแล้ว มีความหมาย

เช่น: "คะแนนเฉลี่ยห้อง = 86.6"

นำไปใช้ตัดสินใจได้

การจัดการข้อมูล = เปลี่ยน ข้อมูลดิบ → สารสนเทศ ที่ใช้งานได้ 💡

👩‍🏫 ก่อนจัดการข้อมูล ต้องจัดตารางให้ถูกโครงสร้างก่อน — Field/Record

🏗️ โครงสร้างตารางข้อมูลที่ดี

ตารางที่ดี: แถวบนสุด = หัวคอลัมน์ (Field) · แต่ละแถว = 1 ระเบียน (Record)

ชื่อ (Field)ห้อง (Field)คะแนน (Field)
↓ แต่ละแถวคือ 1 Record (ข้อมูลของคน 1 คน)
กาญจน์ป.6/185
ขวัญป.6/292
  • ✓มีหัวตารางทุกคอลัมน์ · ห้ามเว้นแถวว่างกลางตาราง · 1 ช่อง = 1 ข้อมูล
👩‍🏫 สาธิต Sort ทั้งน้อยไปมาก และมากไปน้อย บน Excel ที่มีข้อมูลนักเรียน

🔢 Sort — เรียงข้อมูล

Sort = เรียงลำดับข้อมูล ตามคอลัมน์ที่กำหนด
เช่น เรียงคะแนนน้อยไปมาก หรือชื่อตาม A–Z

วิธี Sort

1. คลิก Cell ในคอลัมน์ที่ต้องการเรียง

2. Tab Data → Sort

3. เลือก Ascending (น้อย→มาก)

4. หรือ Descending (มาก→น้อย)

ตัวอย่าง Sort

ชื่อคะแนน
กาญจน์85
ขวัญ92
จิรา78

Sort คะแนน Descending = 92, 85, 78

👩‍🏫 Sort หลายชั้น — เรียงห้องก่อน ในแต่ละห้องเรียงคะแนนอีกที

🔢 Sort หลายชั้น (Multi-level)

เรียงข้อมูลทีละหลายเงื่อนไข — เรียงอันแรกก่อน แล้วเรียงอันที่สองภายในกลุ่ม

วิธีทำ

1. Data → Sort

2. Sort by: ห้อง (A→Z)

3. กด Add Level

4. Then by: คะแนน (มาก→น้อย)

ผลลัพธ์

ห้องคะแนน
ป.6/185
ป.6/178
ป.6/292
ป.6/288

เรียงห้องก่อน แล้วคะแนนในห้อง

👩‍🏫 สาธิต Filter ให้แสดงเฉพาะนักเรียนที่คะแนนมากกว่า 80 หรือเฉพาะชั้น ป.6/1

🔍 Filter — กรองข้อมูล

Filter = แสดงเฉพาะข้อมูลที่ต้องการ
ซ่อนแถวที่ไม่เข้าเงื่อนไข ชั่วคราว

วิธีใช้ Filter

1. คลิก Cell ในตาราง

2. Tab Data → Filter

3. กดลูกศร ▼ ที่หัวตาราง

4. เลือกเงื่อนไขที่ต้องการ

5. กด OK

ประเภท Filter

• Text Filter — กรองข้อความ (เช่น "กรองเฉพาะ ป.6")

• Number Filter — กรองตัวเลข (เช่น "คะแนน > 80")

• Date Filter — กรองวันที่

👩‍🏫 สาธิตเน้นสีเซลล์ที่คะแนนต่ำกว่า 50 เป็นสีแดงอัตโนมัติ — เห็นปัญหาทันที

🎨 Conditional Formatting — เน้นสีตามเงื่อนไข

ใส่สีให้เซลล์อัตโนมัติตามเงื่อนไข — เห็นข้อมูลสำคัญได้ทันตา

วิธีใช้

1. เลือกช่วงข้อมูล

2. Home → Conditional Formatting

3. ตั้งเงื่อนไข เช่น "น้อยกว่า 50"

4. เลือกสีที่ต้องการเน้น

ตัวอย่างใช้งาน

🔴 คะแนน < 50 = แดง (ต้องช่วย)

🟢 คะแนน ≥ 80 = เขียว (เก่ง)

📊 แถบสีตามค่ามาก-น้อย (Data Bars)

👩‍🏫 สาธิต PivotTable สร้างสรุปคะแนนเฉลี่ยแต่ละห้อง — ให้นักเรียนเห็นว่าทำได้ไวมาก

📊 PivotTable — สรุปข้อมูลอัตโนมัติ

PivotTable = ตารางสรุปอัตโนมัติ
จากข้อมูลหลายพัน แถว → สรุปเป็นตารางเดียว

  • 1คลิกในตารางข้อมูล → Tab Insert → PivotTable
  • 2เลือกที่วาง PivotTable (Sheet ใหม่)
  • 3ลาก Field ที่ต้องการไปใน Rows / Columns / Values
  • 4เลือก Sum / Average / Count ตามต้องการ
👩‍🏫 แสดงตัวอย่าง PivotTable ที่สร้างเสร็จแล้ว ให้นักเรียนเห็นผลลัพธ์

👩‍🏫 อธิบาย VLOOKUP ว่าเหมือนค้นหาในสมุดโทรศัพท์ — ใส่ชื่อ ได้เบอร์โทร

🔎 VLOOKUP — ค้นหาข้อมูล

VLOOKUP = ค้นหาข้อมูลในตาราง
บอก "หาค่านี้" → ได้ข้อมูลคอลัมน์ที่ต้องการ

=VLOOKUP(ค่าที่ค้นหา, ช่วงตาราง, เลขคอลัมน์, FALSE)

ตัวอย่าง: =VLOOKUP("กาญจน์", A2:C10, 3, FALSE)
// หา "กาญจน์" ในตาราง A2:C10 แล้วดึงค่าคอลัมน์ที่ 3 (คะแนน)
👩‍🏫 เดินผ่านตัวอย่างทีละขั้น — VLOOKUP หาแถวที่ตรง แล้วดึงคอลัมน์ที่ระบุ

🔎 ตัวอย่าง VLOOKUP: ค้นราคาสินค้า

ตารางอ้างอิง (A:C)

รหัสสินค้าราคา
P01ดินสอ5
P02ปากกา10
P03ยางลบ3

ค้นหา P02 → ราคา?

=VLOOKUP("P02", A2:C4, 3, FALSE)

1️⃣ หา "P02" ในคอลัมน์แรก

2️⃣ เจอที่แถวปากกา

3️⃣ ดึงคอลัมน์ที่ 3 = 10

FALSE = หาแบบตรงเป๊ะ (แนะนำให้ใช้เสมอ) · เลขคอลัมน์นับจากซ้ายของตาราง

🧭 ใช้เครื่องมือไหนเมื่อไหร่?

🔢 Sort — ใช้เมื่อ

• ต้องการเรียงลำดับข้อมูล

• หาค่ามากสุด/น้อยสุดได้ง่าย

เช่น เรียงรายชื่อ A-Z, เรียงคะแนน

🔍 Filter — ใช้เมื่อ

• ต้องการดูข้อมูลบางส่วน

• มีเงื่อนไขเฉพาะเจาะจง

เช่น ดูเฉพาะคะแนน > 80

📊 PivotTable — ใช้เมื่อ

• ต้องการสรุปข้อมูลหลายมิติ

• ข้อมูลเยอะมาก

เช่น สรุปยอดขายรายเดือน

🔎 VLOOKUP — ใช้เมื่อ

• ต้องการดึงข้อมูลจากตารางอื่น

• ค้นหาด้วย Key (รหัส/ชื่อ)

เช่น ดึงราคาจากรหัสสินค้า

👩‍🏫 เชื่อมสู่โลกจริง — องค์กรใหญ่ใช้ข้อมูลตัดสินใจ ให้นักเรียนเห็นความสำคัญ

💡 ข้อมูลช่วยตัดสินใจอย่างไร?

🏪 ในธุรกิจ

• สินค้าไหนขายดี → สั่งเพิ่ม

• ช่วงไหนคนซื้อเยอะ → จัดโปร

• สาขาไหนขาดทุน → ปรับปรุง

🏫 ในโรงเรียน

• วิชาไหนนักเรียนอ่อน → ติวเพิ่ม

• ห้องไหนคะแนนดี → ดูวิธีสอน

• แนวโน้มคะแนนขึ้น/ลง

ตัดสินใจด้วยข้อมูลจริง ดีกว่าการเดา — นี่คือพลังของการจัดการข้อมูล 📊

👩‍🏫 เน้นจริยธรรม — ข้อมูลส่วนตัวของคนอื่นต้องเก็บรักษา ไม่เผยแพร่

🔐 ความเป็นส่วนตัวของข้อมูล

ข้อมูลบางอย่างเป็นความลับส่วนตัว ต้องเก็บรักษา ไม่เผยแพร่

⚠️ ข้อมูลที่ต้องระวัง

• ชื่อ-ที่อยู่-เบอร์โทร

• คะแนน-ข้อมูลส่วนตัวเพื่อน

• รหัสผ่าน-เลขบัตร

✅ ทำอย่างมีจริยธรรม

• ไม่เอาข้อมูลคนอื่นไปเผยแพร่

• ขออนุญาตก่อนใช้ข้อมูลคนอื่น

• เก็บไฟล์ข้อมูลให้ปลอดภัย

จัดการข้อมูลเก่ง ต้องมาพร้อมความรับผิดชอบด้วย 🤝
