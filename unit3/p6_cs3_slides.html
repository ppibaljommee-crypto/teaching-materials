👩‍🏫 ทบทวน If ง่ายๆ ก่อน แล้วค่อยแนะนำ If-Else และ If-ElseIf

🔀 Conditional ขั้นสูง (If-Else)

If ธรรมดา (ป.4–5)

ถ้า มีกำแพง แล้ว
  หมุนซ้าย
จบ

ทำบางอย่างถ้าเงื่อนไขจริง

If-Else ขั้นสูง (ป.6)

ถ้า มีกำแพง แล้ว
  หมุนซ้าย
ไม่งั้น
  เดินหน้า
จบ

เลือกทำ 1 ใน 2 ทาง

If-Else = แยกทางเดิน "ถ้า...ทำA ไม่งั้นทำB" ช่วยให้โปรแกรมชาญฉลาดขึ้น!

👩‍🏫 ยกตัวอย่าง Loop ซ้อนกัน: "วนซ้ำ 3 รอบ ในแต่ละรอบทำซ้ำ 4 ครั้ง = ทำทั้งหมด 12 ครั้ง"

🔄 Nested Loop — Loop ซ้อนกัน

Loop ธรรมดา

ทำซ้ำ 4 ครั้ง
  เดินหน้า
// ทำ 4 ครั้ง

Loop ซ้อน (Nested)

ทำซ้ำ 3 ครั้ง
  ทำซ้ำ 4 ครั้ง
    เดินหน้า
  // รอบด้านใน
// รวม 3×4=12 ครั้ง

Loop ซ้อนกัน ใช้วาด Pattern ซ้ำๆ เช่น ตาราง ลวดลาย สี่เหลี่ยม

👩‍🏫 อธิบาย Function ด้วยตัวอย่าง: "สูตรทำข้าวผัด — ทำครั้งเดียว เรียกใช้ได้หลายครั้ง"

⚙️ Function (ฟังก์ชัน) คืออะไร?

Function = กล่องคำสั่ง ที่ตั้งชื่อไว้
นิยามครั้งเดียว → เรียกใช้ได้กี่ครั้งก็ได้

โดยไม่มี Function

เดินหน้า
หมุนขวา
เดินหน้า
หมุนขวา
// เขียนซ้ำๆ น่าเบื่อ

ใช้ Function

สร้างฟังก์ชัน "เลี้ยวขวา"
  เดินหน้า
  หมุนขวา
เรียก "เลี้ยวขวา"
เรียก "เลี้ยวขวา"
// สั้นกว่ามาก!
👩‍🏫 เน้นว่า Function ช่วยลดโค้ดซ้ำ ถ้าต้องแก้ไข แก้ที่เดียวได้เลย ไม่ต้องแก้ทุกที่

✅ ทำไม Function ถึงดี?

  • 1ลดโค้ดซ้ำ — เขียนครั้งเดียว เรียกใช้หลายครั้ง
  • 2แก้ไขง่าย — แก้ที่ฟังก์ชันเดียว กระทบทุกที่ที่เรียกใช้
  • 3อ่านง่ายขึ้น — ชื่อฟังก์ชันบอกว่าทำอะไร
  • 4นำกลับมาใช้ — ฟังก์ชันดีๆ ใช้ได้ในโปรเจกต์อื่น
👩‍🏫 อธิบายขั้นตอน Debug และแสดงตัวอย่าง Bug ที่พบบ่อยใน Code.org

🐛 Debug — แก้บัคในโปรแกรม

บัคคืออะไร?

Bug = ข้อผิดพลาดในโปรแกรม
ทำให้โปรแกรมทำงาน
ไม่ตรงที่ต้องการ

ทุกนักเขียนโปรแกรม
ต้อง Debug เป็น!

ขั้นตอน Debug

1. อ่านผลลัพธ์ ที่ได้

2. เปรียบเทียบ กับที่ต้องการ

3. หาจุด ที่ผิดพลาด

4. แก้ไข ทีละอย่าง

5. ทดสอบ อีกครั้ง

👩‍🏫 แสดงตัวอย่าง Bug แต่ละชนิด ให้นักเรียนบอกวิธีแก้ก่อน แล้วเฉลย

🔍 Bug ที่พบบ่อยใน Code.org

Bug พบบ่อย

❌ Loop ไม่ครบรอบ (ตัวเลขผิด)

❌ เดินหน้าเกินหรือน้อยกว่าที่ต้องการ

❌ หมุนผิดทิศ (ซ้าย/ขวาสับสน)

❌ ลืมใส่บล็อกท้าย Loop

❌ Function ชื่อสะกดผิด

วิธีแก้

✅ นับก้าวบน Grid ทีละขั้น

✅ วาดเส้นทางบนกระดาษก่อน

✅ ทดสอบทีละบล็อก ไม่รีบ

✅ ใช้ "Step" เพื่อดูทีละขั้น

✅ ถามเพื่อนก่อนถามครู

👩‍🏫 ให้นักเรียนตอบโดยไม่ดูสไลด์ก่อน
