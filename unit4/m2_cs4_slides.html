👩‍🏫 IPO เหมือนสูตรอาหาร: วัตถุดิบ (Input) → กระบวนการทำอาหาร (Process) → อาหารสำเร็จ (Output)

📐 IPO Diagram คืออะไร?

INPUT

ข้อมูลที่โปรแกรมรับเข้า

input(), ค่าตั้งต้น, ไฟล์

→

PROCESS

การประมวลผลข้อมูล

คำนวณ, เปรียบเทียบ, ตัดสินใจ

→

OUTPUT

ผลลัพธ์ที่แสดงออกมา

print(), ไฟล์, กราฟ

IPO Diagram ช่วยให้เราวางแผนโปรแกรมก่อนเขียนโค้ด

👩‍🏫 ให้นักเรียนช่วยกันคิด IPO ของโปรแกรมคิดเงินทอนจากร้านค้า

📝 วางแผนโปรแกรมด้วย IPO Diagram

ทำก่อนเขียนโค้ดทุกครั้ง!

  • 1ระบุ INPUT: โปรแกรมต้องการข้อมูลอะไร? จากผู้ใช้หรือจากที่ไหน?
  • 2ระบุ PROCESS: ต้องคำนวณ ตัดสินใจ หรือทำอะไรกับข้อมูล?
  • 3ระบุ OUTPUT: ผู้ใช้จะเห็นอะไร? แสดงผลอย่างไร?
  • 4ตรวจสอบ: INPUT ทุกอันถูกใช้ใน PROCESS ไหม? OUTPUT ตอบโจทย์ไหม?

🔄 เขียน Python จาก IPO — ขั้นตอน

IPO → Code ทีละส่วน

1. INPUT → เขียน input() และ int()/float()

2. PROCESS → เขียน logic, คำนวณ, if/elif/else

3. OUTPUT → เขียน print() หรือ f-string

ลำดับเขียนโค้ด:

• นำเข้าไลบรารีก่อน (ถ้ามี)

• ส่วน INPUT

• ส่วน PROCESS

• ส่วน OUTPUT

🛡️ ตรวจสอบ Input ให้ปลอดภัย

❌ ปัญหา: ผู้ใช้ใส่ผิด

ถ้าโปรแกรมขอตัวเลข แต่ผู้ใช้พิมพ์ตัวอักษร → โปรแกรม Error และหยุดทำงาน

# ผู้ใช้พิมพ์ "abc" → ValueError!

✅ แก้ด้วย try-except

try:
    age = int(input())
except ValueError:
    print("กรุณาใส่ตัวเลข!")

try = ลองทำ · except = ถ้าพัง ทำอะไรแทน

👩‍🏫 เปรียบ Function กับ "สูตรอาหาร" — สูตรเขียนครั้งเดียว ทำได้กี่ครั้งก็ได้

def — Functions ใน Python

Function คืออะไร?

= กล่องรับคำสั่ง ทำงานแล้วส่งผลกลับ

โครงสร้าง:

def ชื่อ_ฟังก์ชัน(parameter):
    # โค้ดในฟังก์ชัน
    return ค่าที่ส่งกลับ

เรียกใช้: ผลลัพธ์ = ชื่อ_ฟังก์ชัน(ค่า)

ทำไมต้องใช้ Function?

✅ เขียนครั้งเดียว ใช้ได้หลายครั้ง

✅ โค้ดอ่านง่ายขึ้น

✅ แก้บั๊กที่เดียว แก้ได้ทุกที่

✅ แบ่งโปรแกรมใหญ่เป็นส่วนย่อยๆ

โค้ดตัวอย่าง: ฟังก์ชัน BMI

# สร้างฟังก์ชัน
def calc_bmi(weight, height):
    bmi = weight / (height ** 2)
    return round(bmi, 2)

def bmi_status(bmi):
    if bmi < 18.5:
        return "น้ำหนักน้อย"
    elif bmi <= 24.9:
        return "ปกติ ✅"
    else:
        return "น้ำหนักเกิน"

# เรียกใช้ฟังก์ชัน
b = calc_bmi(60, 1.70)
print(f"BMI: {b}")
print(bmi_status(b))

👩‍🏫 เปรียบ List กับ "ตะกร้าผลไม้" — ใส่ได้หลายอย่าง เข้าถึงด้วยหมายเลข (index เริ่มที่ 0)

list — รายการข้อมูล

List คืออะไร?

= กล่องที่เก็บข้อมูลหลายชิ้นไว้ด้วยกัน

fruits = ["แอปเปิล", "มะม่วง", "กล้วย"]
scores = [85, 90, 78, 92]

# เข้าถึงด้วย index (เริ่มที่ 0)
print(fruits[0]) # แอปเปิล
print(fruits[-1]) # กล้วย (ตัวสุดท้าย)

คำสั่งสำคัญของ List

list.append(x) — เพิ่มท้าย

list.remove(x) — ลบออก

len(list) — จำนวนสมาชิก

sum(list) — ผลรวม

max(list) — ค่าสูงสุด

min(list) — ค่าต่ำสุด

for x in list: — วนทุกสมาชิก

👩‍🏫 Dictionary = สมุดรายชื่อ ค้นด้วยชื่อ (key) ได้ค่า (value) — ต่อยอดจาก List

dict — ข้อมูลแบบ key : value

Dictionary คืออะไร?

= เก็บข้อมูลเป็นคู่ key → value เข้าถึงด้วยชื่อ ไม่ใช่ตัวเลข

student = {
    "name": "มานี",
    "age": 14,
    "grade": "A"
}
print(student["name"]) # มานี

List vs Dictionary

📋 List — เข้าถึงด้วยตัวเลข index

scores[0]

📕 Dict — เข้าถึงด้วยชื่อ key

student["name"]

Dict เหมาะกับข้อมูลที่มีชื่อกำกับ เช่น โปรไฟล์นักเรียน

👩‍🏫 กด Run ให้นักเรียนดู สังเกตว่า for loop วนกี่รอบ? ผลลัพธ์ตรงกับที่คาดไหม?

🎓 โปรแกรมใช้ Function + List + Loop

โค้ด: วิเคราะห์คะแนน

def analyze_scores(scores):
    avg = sum(scores) / len(scores)
    highest = max(scores)
    lowest = min(scores)
    return avg, highest, lowest

class_scores = [85, 90, 78, 92, 88]

avg, hi, lo = analyze_scores(class_scores)
print(f"ค่าเฉลี่ย: {avg:.1f}")
print(f"สูงสุด: {hi} | ต่ำสุด: {lo}")

# แสดงคะแนนแต่ละคน
for i, s in enumerate(class_scores, 1):
    print(f"นักเรียน {i}: {s} คะแนน")
