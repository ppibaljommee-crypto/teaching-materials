ScratchJr โปรเจกต์ • คำสั่ง • ลำดับขั้นตอน • การ์ตูนสั้น

👩‍🏫 ทบทวนจากหน่วย 3: นักเรียนเคยทำอะไรใน ScratchJr บ้าง? ให้ยกมือเล่าให้ฟัง

🔄 จำ ScratchJr จากหน่วย 3 ได้ไหม?

  • 1ScratchJr คือแอปสร้างการ์ตูนและเกมง่ายๆ บนแท็บเล็ต
  • 2เราใช้ บล็อกสี ต่อกันเหมือนตัวต่อเลโก้
  • 3แต่ละบล็อกคือ คำสั่ง ที่บอกให้ตัวละครทำ
  • 4ตัวละครเรียกว่า Sprite
  • 5หน่วย 4 นี้เราจะสร้าง การ์ตูนสั้น 3 ฉาก!
👩‍🏫 ให้นักเรียนจำสีแต่ละหมวด — สีบอกหน้าที่ของบล็อก เหมือนสีของไฟจราจร

🌈 บล็อกแต่ละสีทำหน้าที่ต่างกัน

ScratchJr แบ่งบล็อกเป็นหมวดสี จำสีได้ = ใช้เป็นเร็ว!

🟡 เหลือง = เริ่มต้น (Event)
🔵 น้ำเงิน = เคลื่อนที่ (Motion)
🟣 ม่วง = รูปร่าง (Looks)
🩷 ชมพู = เสียง (Sound)
🟠 ส้ม = ควบคุม (Control)

วันนี้เราจะเรียนทุกสี แล้วเอามาต่อกันเป็นการ์ตูน 🎬

👩‍🏫 เปรียบ: เหมือนบอกนักเรียนให้ "ลุกขึ้น" "เดินไปหน้าห้อง" "หยิบหนังสือ" — แต่ละประโยคคือคำสั่ง

💡 การสั่งงาน (Command) คืออะไร?

คำสั่ง = สิ่งที่เราบอกให้คอมพิวเตอร์ทำ

🧑 คำสั่งในชีวิตจริง

• "ลุกขึ้น" → ลุกขึ้น

• "เดินไปข้างหน้า" → เดิน

• "หยุด" → หยุดทันที

• "กลับบ้าน" → เดินกลับ

🐱 คำสั่งใน ScratchJr

• "เดินไป 2 ก้าว" → ตัวละครเดิน

• "หมุน 90 องศา" → ตัวละครหมุน

• "พูดว่า สวัสดี" → ตัวละครพูด

• "เล่นเสียง" → มีเสียงออกมา

👩‍🏫 ยกตัวอย่าง: ถ้าสั่ง "ใส่รองเท้า" ก่อน "ใส่ถุงเท้า" จะเกิดอะไรขึ้น? สนุกมาก!

⚠️ ลำดับคำสั่งสำคัญมาก!

3. เปลี่ยนฉาก

4. พูด "สวัสดี"

→ ตัวละครพูดหลังเปลี่ยนฉากแล้ว ดูแปลก!

✅ ลำดับถูกต้อง

1. พูด "สวัสดี"

2. เดินไปหน้า

3. กระโดด

4. เปลี่ยนฉาก

→ เรื่องเล่าสมเหตุสมผล น่าดู!

💡 คอมพิวเตอร์ทำตามลำดับจากบนลงล่างเสมอ

👩‍🏫 สาธิตบน ScratchJr จริง: กดธงเขียว → ตัวละครเริ่มทำงาน

🚩 Event Blocks ใน ScratchJr

บล็อก "เหตุการณ์" — เริ่มต้นการทำงาน

🟢 When Green Flag Tapped — เมื่อกดธงเขียว
👆 When Tapped — เมื่อแตะตัวละคร
💬 When Message Received — เมื่อรับข้อความ

🟢 When Green Flag

• กดธงเขียว → โปรแกรมเริ่มทำงาน

• ใช้เริ่มต้นโปรแกรมหลัก

• ทุกโปรเจกต์ควรมีบล็อกนี้

👆 When Tapped

• แตะตัวละคร → เริ่มทำงาน

• ใช้ทำปุ่มกดหรืออินเทอร์แอคทีฟ

• แตะกี่ครั้งก็ได้ ทำงานทุกครั้ง

👩‍🏫 Wait = หยุดรอ ทำให้การ์ตูนมีจังหวะ ไม่รีบจนดูไม่ทัน — สาธิตก่อน/หลังใส่ Wait

⏳ Wait Block — รอจังหวะ

⏳ Wait [10] — รอสักครู่

❌ ไม่มี Wait

พูด "สวัสดี"

พูด "ฉันชื่อมานี"

→ ข้อความเด้งเร็วมาก อ่านไม่ทัน!

✅ ใส่ Wait

พูด "สวัสดี"

รอ 10

พูด "ฉันชื่อมานี"

→ มีจังหวะ ดูเป็นธรรมชาติ!

ตัวเลขใน Wait = ระยะเวลารอ (10 ≈ 1 วินาที)

💬 Say Block

• ตัวละครจะแสดงกล่องข้อความ

• พิมพ์ข้อความที่ต้องการ

• ใช้บอกเรื่องราวหรือบทพูด

🎨 Change Scene

• เปลี่ยนพื้นหลัง = เปลี่ยนฉาก

• ใช้เริ่มฉากต่อไปในเรื่อง

• สร้างฉากได้หลายฉาก

👩‍🏫 ให้นักเรียนอัดเสียงตัวเองพูดชื่อของตัวเองลงใน ScratchJr แล้วลองเล่นเสียงนั้น

🔊 Sound Blocks — เสียง

🔊 Play Sound — เล่นเสียง
🎵 Play "Pop" Sound
🎤 Record Sound — อัดเสียง

🔊 Play Sound

• เล่นเสียงที่บันทึกไว้

• ScratchJr มีเสียงสำเร็จรูปให้เลือก

• เสียงเล่นพร้อมกับการเคลื่อนที่ได้

🎤 Record Sound

• กดปุ่มแดงเพื่ออัดเสียง

• อัดได้หลายคลิปในโปรเจกต์เดียว

• ใช้เสียงตัวเองทำให้การ์ตูนมีชีวิตชีวา!

🎯 ลองทำ!

👩‍🏫 อธิบาย Loop = ทำซ้ำ เปรียบกับ "กระโดดเชือก 10 ครั้ง" ถ้าไม่มี Loop ต้องต่อบล็อก 10 บล็อก!

👩‍🏫 ปัญหายอดฮิตของ ScratchJr — ให้นักเรียนรู้วิธีแก้เองก่อนยกมือถาม

🐛 ทำไมการ์ตูนไม่ทำงาน? (Debug)

  • 1❌ ลืมบล็อกเริ่ม → ต้องมี 🟢 เมื่อกดธงเขียว ที่หัวสุด
  • 2❌ บล็อกไม่ติดกัน → ลากให้ชนกันจนคลิกเข้าที่
  • 3❌ ใส่เลขเป็น 0 → ตัวละครไม่ขยับ ใส่เลขมากกว่า 0
  • 4❌ เร็วเกินไป → ใส่บล็อก ⏳ รอ คั่นระหว่างคำสั่ง

🎬 ออกแบบโปรเจกต์การ์ตูน 3 ฉาก

  • 1คิดเรื่อง: โปรเจกต์ของเราพูดถึงอะไร? (สัตว์, ผจญภัย, ชีวิตประจำวัน)
  • 2วางแผนฉาก: ฉาก 1 = เริ่มต้น | ฉาก 2 = กลาง | ฉาก 3 = จบ
  • 3เลือกตัวละคร: มีกี่ตัว? แต่ละตัวทำอะไร?
  • 4เขียน Script: ตัวละครพูดว่าอะไร? เคลื่อนที่อย่างไร?
  • 5ลงมือสร้าง: ต่อบล็อกตามที่วางแผน
👩‍🏫 เดินดูการทำงานของนักเรียน ช่วยแก้ปัญหาเมื่อบล็อกไม่ทำงาน ชม: "โปรเจกต์ดูน่าสนใจมาก!"

งาน: โปรเจกต์ ScratchJr การ์ตูนสั้น

📋 สิ่งที่ต้องมีในโปรเจกต์

✅ อย่างน้อย 3 ฉาก (ฉากเริ่ม กลาง จบ)
✅ ตัวละครอย่างน้อย 1 ตัว มีการเคลื่อนที่
✅ ตัวละครพูดด้วย Say block
✅ มีเสียงหรือดนตรีประกอบ
✅ ใช้ Event block (Green Flag หรือ When Tapped)

👩‍🏫 ให้นักเรียน 4-5 คนฉายการ์ตูนหน้าชั้น ชมเชยความตั้งใจของทุกคน

🎤 นำเสนอการ์ตูนของเรา

🗣️ เล่าโปรเจกต์

• การ์ตูนของเราเรื่องอะไร

• มีตัวละครอะไรบ้าง

• ใช้บล็อกอะไรบ้าง

• ภูมิใจตรงไหนที่สุด

💖 ชมผลงานเพื่อน

• ตั้งใจดูเพื่อนนำเสนอ

• ปรบมือให้กำลังใจ

• บอกสิ่งที่ชอบในงานเพื่อน
