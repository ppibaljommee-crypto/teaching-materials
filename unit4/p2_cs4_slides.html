สำรวจสัตว์โปรด
ในชั้นเรียน

การเก็บข้อมูล • กราฟแท่ง • วิเคราะห์ผล

👩‍🏫 ยกตัวอย่าง: "อุณหภูมิวันนี้ 30°C" = ข้อมูล, "สุนัขชนะแมว 8 ต่อ 6 คะแนน" = ข้อมูล

📊 ข้อมูล (Data) คืออะไร?

ข้อมูล = สิ่งที่เราสังเกตและบันทึกเพื่อนำมาใช้ประโยชน์

📌 ตัวอย่างข้อมูล

• จำนวนนักเรียนชอบสุนัข: 8 คน

• อุณหภูมิห้องเรียน: 27°C

• คะแนนสอบวิชาคณิต: 75/100

• เวลาออกกำลังกาย: 30 นาที/วัน

🎯 ทำไมต้องเก็บข้อมูล?

• ช่วยตัดสินใจได้ดีขึ้น

• หาคำตอบให้คำถามได้

• เปรียบเทียบสิ่งต่างๆ ได้

• วางแผนได้แม่นยำขึ้น

👩‍🏫 ก่อนเก็บข้อมูลต้องรู้ว่าจะถามอะไร — ตั้งคำถามให้ชัดเจนก่อน

❓ ตั้งคำถามก่อนเก็บข้อมูล

นักสำรวจที่ดี เริ่มจากคำถามที่ชัดเจนเสมอ

❌ คำถามไม่ชัด

• "สัตว์เป็นยังไง?"

• "ชอบอะไร?"

→ ตอบได้หลายแบบ เก็บข้อมูลยาก

✅ คำถามชัดเจน

• "สัตว์โปรดของเธอคืออะไร?"

• "เลือก 1 อย่าง: สุนัข/แมว/ปลา"

→ ตอบตรงประเด็น นับได้ง่าย

คำถามวันนี้: "สัตว์โปรดของเพื่อนในห้องคืออะไร?"

👩‍🏫 อธิบาย 3 วิธี ถามว่า "วันนี้เราจะใช้วิธีไหนเก็บข้อมูลสัตว์โปรด?"

🔍 วิธีเก็บข้อมูล 3 แบบ

  • 1สำรวจ (Survey) — ถามทุกคนในกลุ่มแล้วบันทึก เหมาะกับหัวข้อง่ายๆ เช่น สัตว์โปรด
  • 2สัมภาษณ์ (Interview) — ถามคำถามโดยตรงเพื่อข้อมูลลึกกว่า เช่น "ทำไมชอบสุนัข?"
  • 3สังเกต (Observation) — มองดูแล้วบันทึก ไม่ต้องถาม เช่น นับนักเรียนที่ใส่แว่น

วันนี้เราจะ สำรวจ สัตว์โปรดของเพื่อนในชั้นเรียน!

👩‍🏫 สาธิตวิธีลงตาราง: ถามนักเรียนทีละคน ฟังคำตอบ ขีดในช่องที่ตรงกัน

👩‍🏫 ย้ำว่าข้อมูลผิด = สรุปผิด ให้นักเรียนระวังตอนเก็บและนับ

✅ ข้อมูลถูกต้องสำคัญที่สุด

ข้อมูลผิด → สรุปผิด → ตัดสินใจผิด
เก็บข้อมูลให้ครบและถูกต้อง

⚠️ ข้อผิดพลาดที่พบบ่อย

• นับซ้ำคนเดิม 2 ครั้ง

• ลืมนับบางคน

• ขีด Tally ผิดช่อง

• รวมเลขผิด

✅ วิธีป้องกัน

• ถามทีละคน ตามลำดับ

• ทำเครื่องหมายคนที่ถามแล้ว

• นับรวมซ้ำอีกครั้ง

• เช็คผลรวม = จำนวนคนทั้งหมด

👩‍🏫 สอนวิธีขีด Tally: 4 ขีดตั้ง แล้วขีดที่ 5 ขวาง — นับง่าย รวดเร็ว

📊 กราฟแท่ง (Bar Chart) คืออะไร?

ส่วนประกอบของกราฟ

• แกน X (แนวนอน) = ประเภทข้อมูล เช่น ชนิดสัตว์

• แกน Y (แนวตั้ง) = ตัวเลขจำนวน

• แท่ง = สูงกว่า = จำนวนมากกว่า

• ชื่อกราฟ = บอกว่ากราฟนี้แสดงอะไร

📋 ขั้นตอน

1️⃣ สำรวจสัตว์โปรดของเพื่อนในห้อง บันทึกด้วย Tally
2️⃣ นับรวมและกรอกลงตารางใบงาน
3️⃣ วาดกราฟแท่งในกระดาษ Grid
4️⃣ เขียนสรุป: "จากข้อมูลพบว่า..."

👩‍🏫 ให้นักเรียนเห็นว่ารอบตัวเต็มไปด้วยการเก็บและใช้ข้อมูล

🌍 ข้อมูลและกราฟอยู่รอบตัวเรา

📺 ที่เราเห็นบ่อย

• พยากรณ์อากาศ (กราฟอุณหภูมิ)

• คะแนนกีฬา (ตารางคะแนน)

• ยอดวิว/ไลก์ในแอป

• ราคาของในร้านค้า

🎯 ใช้ข้อมูลทำอะไร

• ครูดูคะแนนเพื่อช่วยนักเรียน

• ร้านค้าดูว่าของอะไรขายดี

• หมอดูข้อมูลสุขภาพคนไข้

เก็บข้อมูลเป็น = เข้าใจโลกรอบตัวได้ดีขึ้น 📊

👩‍🏫 ให้นักเรียน 3-4 คนนำกราฟมาเล่าผลสำรวจ ฝึกการนำเสนอข้อมูล

🎤 นำเสนอผลสำรวจ

เล่าผลสำรวจให้เพื่อนฟัง โดยใช้ กราฟ ช่วย

  • 1บอกว่าสำรวจเรื่องอะไร จากใครบ้าง
  • 2ชี้กราฟ บอกอันดับ มากสุด-น้อยสุด
  • 3สรุป: "จากข้อมูลพบว่า..."

พูดจากข้อมูลจริง = น่าเชื่อถือ! 🌟
