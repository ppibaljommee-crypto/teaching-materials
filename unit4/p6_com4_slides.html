ส่วนประกอบของเว็บ

🌐 URL = ที่อยู่เว็บไซต์ เช่น google.com

📄 หน้าเว็บ (Page) = แต่ละหน้าในเว็บไซต์

🏠 Homepage = หน้าแรกของเว็บ

🔗 ลิงก์ (Link) = คลิกแล้วไปหน้าอื่น

เว็บไซต์ vs โซเชียลมีเดีย

🌐 เว็บไซต์ = ของเราเอง ควบคุมได้เอง

📱 โซเชียล = ขึ้นอยู่กับแพลตฟอร์ม เปลี่ยนได้ตลอด

เว็บไซต์ดูมืออาชีพกว่า เหมาะกับนำเสนอผลงาน

📋 วางแผนเว็บไซต์ก่อนสร้าง

  • 1หัวข้อเว็บ: เว็บนี้พูดถึงอะไร? (ตัวเอง, งานอดิเรก, โปรเจกต์)
  • 2จำนวนหน้า: มีกี่หน้า? ชื่อแต่ละหน้าคืออะไร?
  • 3เนื้อหา: แต่ละหน้ามีอะไรบ้าง? รูป ข้อความ วิดีโอ?
  • 4ธีม/สี: เว็บควรมีสีอะไร บรรยากาศแบบไหน?
  • 5ผู้ชม: ใครจะมาดูเว็บนี้? ครู เพื่อน พ่อแม่?

👩‍🏫 สาธิตทีละขั้นบน Projector ให้นักเรียนทำตาม ช้าๆ รอทุกคน

🚀 สร้างเว็บไซต์ใหม่ใน Google Sites

  • 1เปิด sites.google.com แล้ว Login ด้วย Google Account
  • 2คลิก + New Site (ปุ่มสีแดงด้านขวาล่าง)
  • 3พิมพ์ ชื่อเว็บ ที่ช่อง "Untitled Site"
  • 4เลือก ธีมสี จากแถบด้านขวา
  • 5พิมพ์ ชื่อหัวเว็บ (Title) ตรงกลางหน้า
  • 6เว็บบันทึกอัตโนมัติ ไม่ต้องกด Save!
👩‍🏫 สาธิตการเพิ่ม Text box และ Image แล้วให้นักเรียนลองเพิ่มด้วยตัวเองทันที

✏️ เพิ่มข้อความและรูปภาพ

📝 เพิ่มข้อความ

1. คลิก Insert → Text box

2. คลิกในหน้าเว็บที่ต้องการ

3. พิมพ์ข้อความ

4. เลือกสไตล์: Normal / Heading / Subheading

💡 ลาก Text box ย้ายตำแหน่งได้

🖼️ เพิ่มรูปภาพ

1. คลิก Insert → Image

2. เลือก Upload (จากเครื่อง) หรือ Search the web

3. เลือกรูปที่ต้องการ

4. ปรับขนาดโดยลากมุมรูป

💡 ใช้รูปฟรีจาก Unsplash ใน Google Sites

👩‍🏫 ทุกหน้าเว็บมีโครงสร้างคล้ายกัน: หัว เนื้อหา ท้าย

🧱 โครงสร้างหน้าเว็บที่ดี

  • 1Header (ส่วนหัว) — ชื่อเว็บ/โลโก้ + เมนูนำทาง อยู่บนสุด
  • 2Hero (ส่วนเด่น) — รูปใหญ่ + ข้อความต้อนรับ ดึงดูดสายตา
  • 3Content (เนื้อหา) — ข้อมูลหลัก แบ่งเป็นส่วนๆ อ่านง่าย
  • 4Footer (ส่วนท้าย) — ข้อมูลติดต่อ เครดิต ลิงก์เพิ่มเติม

วางเนื้อหาสำคัญไว้บนๆ — คนดูส่วนบนก่อนเสมอ

👩‍🏫 สาธิตการสร้างหน้าใหม่และ Navigation menu ที่ปรากฏอัตโนมัติ

📄 สร้างหน้าใหม่ (Navigation)

  • 1ด้านขวาบน คลิก Pages (ไอคอนกระดาษ)
  • 2คลิก + ที่ด้านล่าง ของรายการหน้า
  • 3พิมพ์ ชื่อหน้าใหม่ เช่น "เกี่ยวกับฉัน" "ผลงาน" "ติดต่อ"
  • 4Menu Navigation จะเพิ่มหน้าใหม่อัตโนมัติ
  • 5สลับระหว่างหน้าโดยคลิกชื่อหน้าใน Pages panel

💡 เว็บที่ดีควรมีอย่างน้อย 3 หน้า: หน้าแรก + เนื้อหา + ติดต่อ

👩‍🏫 ลิงก์ทำให้เว็บเชื่อมโยงกัน คลิกแล้วไปหน้าอื่นหรือเว็บอื่นได้

🔗 ลิงก์ (Hyperlink) เชื่อมหน้า

วิธีใส่ลิงก์

1. เลือกข้อความหรือรูป

2. คลิกไอคอน 🔗 Insert link

3. เลือกหน้าในเว็บ หรือวาง URL ภายนอก

4. คลิก Apply

ลิงก์ 2 แบบ

📄 ลิงก์ภายใน — ไปหน้าอื่นในเว็บเรา

🌐 ลิงก์ภายนอก — ไปเว็บอื่น เช่น YouTube

ใช้ข้อความลิงก์ที่สื่อความหมาย เช่น "ดูผลงาน" ไม่ใช่ "คลิกที่นี่"

👩‍🏫 สาธิตการฝัง YouTube video และ Google Maps — ทำให้เว็บน่าสนใจมากขึ้น

📱 ตรวจสอบเว็บบนมือถือ (Preview)

คนส่วนใหญ่เปิดเว็บบนมือถือ ต้องดูดีทุกจอ

วิธี Preview

1. คลิกไอคอน 👁️ Preview มุมขวาบน

2. เลือกดูแบบ 📱 มือถือ / 💻 แท็บเล็ต / 🖥️ คอม

เคล็ดลับ

Google Sites ปรับให้อัตโนมัติ แต่ควรเช็กเสมอ

👩‍🏫 สาธิต Publish แล้วเปิด URL ที่ได้บน Projector — ให้นักเรียนเห็นเว็บจริงบนอินเทอร์เน็ต ตื่นเต้นมาก!

🚀 เผยแพร่เว็บ — Publish

  • 1คลิกปุ่ม Publish มุมขวาบน
  • 2ตั้ง Web address — ชื่อ URL ที่ต้องการ (ใช้ตัวพิมพ์เล็ก ไม่มีช่องว่าง)
  • 3เลือก Who can view: Anyone with the link (แนะนำสำหรับการบ้าน)
  • 4คลิก Publish
  • 5Copy URL แล้วส่งครู → sites.google.com/view/ชื่อที่ตั้ง
  • 6ทดสอบเปิดด้วย Incognito Mode
👩‍🏫 เว็บที่เผยแพร่ทุกคนเห็นได้ ต้องระวังไม่ใส่ข้อมูลส่วนตัว — เชื่อมกับหน่วยความปลอดภัย

🔐 ระวังข้อมูลส่วนตัวบนเว็บ

เว็บที่ Publish แล้ว ทุกคนบนอินเทอร์เน็ตเห็นได้

🚫 อย่าใส่ในเว็บ

• ที่อยู่บ้าน เบอร์โทร

• ชื่อ-นามสกุลเต็ม

• รูปที่บอกตำแหน่งบ้าน/โรงเรียน

• ข้อมูลคนอื่นโดยไม่ขอ

✅ ใส่ได้ปลอดภัย

• ชื่อเล่น/ชื่อโปรเจกต์

• ผลงาน งานเรียน

• รูปที่ไม่บอกข้อมูลส่วนตัว

• อ้างอิงรูป/ข้อมูลที่นำมาใช้

ก่อน Publish → ตรวจว่าไม่มีข้อมูลส่วนตัวหลุดออกไป
