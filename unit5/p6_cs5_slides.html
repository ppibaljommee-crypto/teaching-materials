👩‍🏫 อธิบาย Phishing ด้วยตัวอย่างอีเมลปลอมจากธนาคาร

🎣 รู้จัก Phishing

Phishing = หลอกล่อให้เราเปิดเผยข้อมูลสำคัญ

🚩 สัญญาณเตือน

• ชื่อผู้ส่งไม่ชัดเจน

• URL ผิดสังเกต

• ขอข้อมูลส่วนตัว

• บอกว่า "ด่วน! บัญชีถูกล็อค"

• มีการสะกดผิด

✅ วิธีรับมือ

• ไม่คลิกลิงก์ในเมล

• ตรวจสอบ URL ให้ดี

• โทรถามโดยตรงแทน

• แจ้งผู้ปกครองหรือครู

👩‍🏫 ให้ยกมือตอบก่อนกดเฉลย

ถ้าได้รับอีเมลขอให้กรอกรหัสผ่าน เราควรทำอย่างไร?

👩‍🏫 อธิบาย Malware ว่าเข้ามาได้ยังไง และผลที่ตามมา

🦠 รู้จัก Malware

📌 Malware เข้ามาได้จาก

• เปิดไฟล์แนบอีเมล

• Download จากเว็บไม่ดี

• คลิกโฆษณาน่าสงสัย

• USB ที่มีไวรัส

🛡️ ป้องกันได้ด้วย

• ติดตั้ง Antivirus

• อัปเดตระบบสม่ำเสมอ

• ไม่ Download ของฟรีน่าสงสัย

• สแกน USB ก่อนใช้

👩‍🏫 อธิบาย Scam หลอกเงิน ยกตัวอย่างหลอกซื้อของออนไลน์

💰 รู้จัก Scam (หลอกเงิน)

Scam = หลอกให้โอนเงิน หรือซื้อของที่ไม่มีจริง

🚩 รูปแบบที่พบบ่อย

• "ถูกรางวัล! โอนค่าธรรมเนียมก่อน"

• ร้านออนไลน์ราคาถูกผิดปกติ

• ขอยืมเงินผ่านบัญชีปลอม

✅ วิธีรับมือ

• ไม่โอนเงินให้คนแปลกหน้า

• ตรวจสอบร้านค้าก่อนซื้อ

• ปรึกษาผู้ปกครองทุกครั้ง

👩‍🏫 Cyberbullying — ชวนคุยว่าเคยเห็นการกลั่นแกล้งออนไลน์ไหม

😔 Cyberbullying (กลั่นแกล้งออนไลน์)

การใช้คำพูด/รูป ทำร้ายจิตใจคนอื่นบนโลกออนไลน์

❌ ตัวอย่าง

• ด่าว่าหรือล้อเลียนในคอมเมนต์

• แชร์รูปคนอื่นเพื่อล้อ

• ตั้งกลุ่มนินทาเพื่อน

✅ ถ้าเจอ ให้...

• ไม่ตอบโต้ เก็บหลักฐาน

• บล็อกและรายงาน

• บอกผู้ปกครองหรือครู

👩‍🏫 สอนการสร้างรหัสผ่านที่แข็งแรง ให้นักเรียนลองคิดรหัสผ่าน

🔐 รหัสผ่านที่ดีเป็นยังไง?

รหัสผ่านที่แข็งแรง = ปลอดภัย

✅ รหัสที่ดี

• ยาวอย่างน้อย 8 ตัว

• มีตัวพิมพ์ใหญ่-เล็ก

• มีตัวเลขและอักขระพิเศษ

• ไม่ใช้ชื่อหรือวันเกิด

❌ รหัสที่อ่อนแอ

• 12345678

• password

• ชื่อตัวเอง

• วันเกิด เช่น 2550

👩‍🏫 อธิบายการยืนยันตัวตน 2 ขั้น (2FA) ว่าช่วยกันแฮกได้ยังไง

🔑 ยืนยันตัวตน 2 ขั้น (2FA)

2FA = ใช้รหัสผ่าน + อีกหนึ่งขั้น เพื่อความปลอดภัย

📲 ขั้นที่สองคืออะไร

• รหัส OTP ส่งเข้ามือถือ

• แอปยืนยันตัวตน

• ลายนิ้วมือ / สแกนหน้า

💡 ทำไมถึงปลอดภัยขึ้น

• ถึงรหัสผ่านรั่ว ก็เข้าไม่ได้

• ต้องมีมือถือเราด้วย

• ป้องกันการแฮกบัญชี

🎯 ลองคิดดู!

รหัสผ่านข้อใด "แข็งแรง" และปลอดภัยที่สุด?

👩‍🏫 อธิบายความเป็นส่วนตัว ข้อมูลอะไรไม่ควรโพสต์/บอกใคร

🔒 ปกป้องข้อมูลส่วนตัว

ข้อมูลบางอย่างไม่ควรบอกหรือโพสต์ออนไลน์

🚫 ไม่ควรเปิดเผย

• เลขบัตรประชาชน

• ที่อยู่บ้าน / เบอร์โทร

• รหัสผ่าน

• รูปที่บอกตำแหน่งบ้าน/โรงเรียน

✅ ควรทำ

• ตั้งบัญชีเป็นส่วนตัว

• รับเพื่อนเฉพาะคนที่รู้จัก

• ถามผู้ปกครองก่อนโพสต์

👩‍🏫 สรุปหลักการ THINK ก่อนโพสต์/คลิก

🧠 THINK ก่อนทำอะไรออนไลน์

  • TTrue — จริงหรือเปล่า? ตรวจสอบก่อน
  • HHelpful — มีประโยชน์ไหม?
  • IInspiring — สร้างสรรค์หรือทำร้ายคนอื่น?
  • NNecessary — จำเป็นต้องทำจริงไหม?
  • KKind — กรุณาต่อคนอื่นไหม?
👩‍🏫 ให้นักเรียนร่วมกันวิเคราะห์สถานการณ์ก่อนเฉลย

🎮 สถานการณ์: ทำอย่างไร?

ได้รับอีเมลแจ้งว่า "คุณได้รางวัลล้านบาท! กรอกเลขบัตรประชาชนเพื่อรับรางวัล"

🚨 นี่คือ Phishing/Scam! — ไม่กรอก ลบทิ้ง แจ้งผู้ปกครองทันที
👩‍🏫 สถานการณ์ที่ 2 — เรื่องการกลั่นแกล้งออนไลน์
สถานการณ์ที่ 2

💬 สถานการณ์: ทำอย่างไร?

เห็นเพื่อนในกลุ่มแชร์รูปล้อเลียนเพื่อนอีกคน แล้วชวนเราคอมเมนต์ด่าด้วย

✅ ไม่ร่วมด้วย! — เก็บหลักฐาน บอกครู/ผู้ปกครอง และให้กำลังใจเพื่อนที่ถูกล้อ
👩‍🏫 อธิบายความเสี่ยงของ Wi-Fi สาธารณะ เช่นในห้าง

📶 Wi-Fi สาธารณะปลอดภัยไหม?

Wi-Fi ฟรีในที่สาธารณะ อาจไม่ปลอดภัย

⚠️ ความเสี่ยง

• คนอื่นอาจดักข้อมูลเราได้

• Wi-Fi ปลอมที่ตั้งชื่อหลอก

• ไม่ควรทำธุรกรรมเงิน

✅ ใช้อย่างปลอดภัย

• ไม่ล็อกอินบัญชีสำคัญ

• ดูเฉพาะข้อมูลทั่วไป

• ใช้เน็ตมือถือถ้าทำเรื่องสำคัญ
